# A) ArgoCD ?

ArgoCD 는 GitOps 방식으로 관리되는 Manifest(yaml) 파일의 변경사항을 감시하며, 현재 배포된 환경의 상태와 Github Manifest 파일에 정의된 상태를 동일하게 유지하는 역할을 수행한다.

![](https://i.imgur.com/UcyiING.png)

Argo CD 는 CD 과정을 진행하는데 Kubernetes 로 배포한다.

Argo CD is a declarative, GitOps continuous delivery tool for Kubernetes).
