# A) Pre-Order ?

Pre-order traversal 은 tree 를 순회할 때 현재 node 를 먼저 방문하고, 그 다음 left subtree, right subtree 순서로 방문하는 방식이다.

```text
root -> left -> right
```

# B) 언제 쓰나

Tree 구조를 직렬화하거나, root 의 정보를 먼저 처리해야 하는 DFS 계열 traversal 에서 사용한다.
