# A) Selection Bias ?

* Two types of selection biases
	* system item selection process
	* users’ self-selection behavior
* Example

![](https://firebasestorage.googleapis.com/v0/b/firescript-577a2.appspot.com/o/imgs%2Fapp%2Fwoosung_graph%2Ft-B0Cq8m48.png?alt=media&token=a0241a3f-8f2b-48db-82a4-d14a2e3c84e6)

* 내 의견
	* viewable impression log 를 수집할 수 있다면 self-selection behavior 보다는 system item selection process 에 의해 큰 영향을 받을 것이다.
		* self-selection behavior 는 explicit feedback 을 가정했을 때 얘기고, implicit feedback 개념 하에서는 bias effect 가 조금은 줄어들 지 않을까 싶음
