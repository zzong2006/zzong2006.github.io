# A) Eigenvector ?

matrix $\boldsymbol{A}$ 의 eigenvector 는 $\boldsymbol{A}\boldsymbol{v}=\lambda\boldsymbol{v}$ 를 만족하는 vector $\boldsymbol{v}$ 를 의미한다.

* $\lambda$ 는 [[eigenvalue]]

# B) 특징

* rescaled vector $s\boldsymbol{v}\text{for}s\in\mathbb{R},s\neq0$ 는 $\boldsymbol{v}$ 와 동일한 [[eigenvalue]] 를 가진다.
