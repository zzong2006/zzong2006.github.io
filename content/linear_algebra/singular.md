# Singular ?

A square matrix with [[Linear Independence|linearly dependent]] columns is known as singular.

# Properties

singular 의 반대는 invertible matrix 다. 즉, square ($m\times n,m=n$) 이면서 모든 열 벡터가 [[Linear Independence|linearly independent]] 한 matrix 를 의미한다.

If $A$ ($Ax=b$) is not square or is square but singular, solving the equation is still possible. 그러나 [[Inverse matrix]] 를 통해 solution 을 구할 수는 없다.
