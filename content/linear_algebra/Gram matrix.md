# A) Gram Matrix ?

어떤 벡터들 $v_{1}, \ldots, v_{n}$ 로 구성된 집합의 그람 행렬은 각 벡터들의 [[dot product|내적]] (정확히는 inner product) $G_{i j}=\left\langle v_{i}, v_{j}\right\rangle$ 이 원소로 표현된 행렬을 의미한다.

즉, $v_{1}, \ldots, v_{n}$ 가 행렬 $X$ 의 column 이라면, Gram matrix 는 $X^{\top} X$ 로 표현될 수 있다.
