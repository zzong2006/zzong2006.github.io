# I. Adjacency Matrix ?

adjacency matrix 는 정방 행렬로, 유한한 그래프를 표현하기 위한 행렬이다.

이 행렬의 원소는 두 vertices 가 그래프 상에서 서로 인접 (adjacent) 한지 여부를 나타낸다. 일반적인 유한 그래프에서는 (0, 1)- 행렬로 표현된다 (대각 원소는 모두 $0$)
