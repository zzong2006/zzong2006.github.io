# Orthonormal ?

두 벡터 $\boldsymbol{b}_{i}$ 와 $\boldsymbol{b}_{j}$ 가 [[orthonormal]] (정규 직교) 할 경우, 다음을 만족한다.

* $i\neq j$ and $\boldsymbol{b}_{i}^{\top}\boldsymbol{b}_{j}=0$ ([[orthogonal]])
* $i=j$ and $\boldsymbol{b}_{i}^{\top}\boldsymbol{b}_{j}=1$ ( unit norm )

## Orthonormal Matrix

orthonormal matrix is a real square matrix whose columns and rows are orthonormal vectors.
