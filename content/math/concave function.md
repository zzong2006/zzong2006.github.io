# 2. 주어진 함수가 Concave 인지 확인하는 법

2 차 미분이 음수인것을 확인하면 된다.

## 2.1. 예시

Q) $g(x)=\log x$ 가 concave 한지 판단하라.

A) $\displaystyle g^{\prime\prime}(x)=(\log(x))^{\prime\prime}=\left(\frac{1}{x}\right)^{\prime}=-\frac{1}{x^{2}}$ 를 $x>0$ 일 때 만족하므로, $g(x)$(log 함수) 는 concave function 이다.
