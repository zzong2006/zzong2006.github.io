# Indicator Function ?

Products of Indicator Functions

* Because $0·1=0$, the product of indicator functions can be combined into a single indicator function with a modified condition.
* Examples
	* $I_{\{x<5\}}\cdot I_{\{x\geq0\}}=I_{\{0\leq x<5\}}$
	* $\displaystyle\prod_{i=1}^{n}I_{\left\{x_{i}<2\right\}}=I_{\left\{x_{i}<2\text{forall}i\right\}}=I_{\left\{\max_{i}x_{i}<2\right\}}$
