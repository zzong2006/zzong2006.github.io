# Constrained Optimization Problem ?

* 예시
	* Maximize $f(x,y)=x^2y$ on the set $x^2+y^2=1$ (unit circle, constrained hole)
		* $f(x,y)=0.3$ 인 경우는 $x^2+y^2=1$ 를 만족하는 $x,y$ 를 찾을 수 있는데, $f(x,y)=1$ 는 불가능
