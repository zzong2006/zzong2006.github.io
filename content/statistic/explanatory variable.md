# A) Explanatory Variable ?

this variable explains the variation in the [[response variable]]

[[supervised learning]] 중 어떤 한 task 는 feature 의 집합이 주어졌을 때, 숫자형 target 값을 예측하는 것인데, 여기서 feature 를 predictor 라 부른다 (e.g. 마일리지, 연식 등이 주어졌을 때 자동차 가격 예측하기)

# B) 특성

* [[collinearity]] : 상호 연관된 예측 변수들을 사용하면 [[regression]] 계수의 부호와 값의 의미를 해석하기가 어려울 수 있다.
