# A) Gamma Function ?

Gamma function 은 factorial 을 실수/복소수 영역으로 확장한 함수다.

$$
\Gamma(\alpha)=\int_0^\infty x^{\alpha-1}e^{-x}dx
$$

양의 정수 $n$ 에 대해 다음 관계를 가진다.

$$
\Gamma(n)=(n-1)!
$$

# B) 분포에서의 역할

[[Gamma distribution]], [[Beta distribution]], [[Dirichlet distribution]] 같은 확률분포의 normalizing constant 에 자주 등장한다.
