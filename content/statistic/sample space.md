# Sample Space ?

The set of all possible outcomes of a statistical [[experiment]] is called the sample space and is represented by the symbol $S$.

sample space 의 각 결과: an element or a member of the sample space, or simply a sample point

예시) coin toss

$$
S=\{H, T\}
$$

sample space 가 매우 많은 point 를 가지는 경우, statement 또는 rule method 를 통해서 표현이 가능하다.

$$
S=\{x \mid x \text { is a city with a population over } 1 \text { million }\}
$$

# Null Set

sample space 또는 [[event]] 개수가 0 개인 집합: $A=\phi$
