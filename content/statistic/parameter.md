# A) Parameter ?

관측 불가능한 variables 의 집합 (반대: [[data]])

# B) In Statistic

모집단에서 계산될 수 있는 통계치를 parameter 라 부르며, 표본집단에서 계산될 수 있는 통계치를 statistic 이라 부른다.

## B.1) 예시

모집단의 평균 $\mu$ 는 parameter, 표본집단의 평균 $\bar{x}$ 는 statistic
