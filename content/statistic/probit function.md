# Probit Function ?

probit 함수는 [[quantile function]] 의 일종으로, 표준 [[Gaussian distribution|정규 분포]] 의 [[Cumulative Distribution Function|CDF]] $\Phi(z)$ 에 대한 inverse 함수를 의미한다:

$$
\operatorname{probit}(p)=\Phi^{-1}(p) \quad \text { for } \quad p \in(0,1)
$$
