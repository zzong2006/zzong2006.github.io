# A) 피어슨 상관 계수

두 랜덤 변수 $X, Y$ 에 대해서 피어슨 상관 계수는 다음과 같이 계산된다.

$$
\rho_{X, Y}=\frac{\operatorname{cov}(X, Y)}{\sigma_{X} \sigma_{Y}}
$$

* cov 는 [[covariance]], 그리고 분모는 각각 $X, Y$ 의 [[standard deviation]]

# B) 해석

일반적으로 두 변수의 [[correlation]] 정도를 측정하는데 사용된다. `[-1, 1]` 사이의 값을 가지며, 0 에 가까울수록 독립이고, 끝 값에 가까울수록 양 또는 음의 상관관계를 가진다.
