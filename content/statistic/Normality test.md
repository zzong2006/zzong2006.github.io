# A) Noarmlity Test 란?

데이터셋의 분포가 정규 분포 [[Gaussian distribution]] 을 따르는지 검사하는 것

Normality Test 말고도 [[Q-Q plot]] 이나 [[Frequency Distribution]] 을 통해 시각화에 기반하여 [[Gaussian distribution]] 을 따르는 지 확인할 수 있다.

# B) Test 과정

여러 방법들이 존재하는데, 일반적으로 다음과 같은 흐름으로 진행된다.

귀무가설과 영가설을 설정하여 [[p-value]] 를 구한뒤, 귀무가설을 받아들일지 말지 결정한다.

[[null hypothesis]]: 관찰한 데이터셋의 표본들은 정규 분포에서 가져온 것이다.

[[alternative hypothesis]]: 관찰한 데이터셋의 표본들은 정규 분포가 아닌 분포에서 가져왔다.
