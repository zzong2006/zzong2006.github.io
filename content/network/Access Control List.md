# A) Access Control List ?

개체나 개체 속성에 적용되어 있는 허가 목록을 의미한다.

이 목록은 다음과 같은 내용을 지정하고 있다.

* 누가 또는 무엇이 객체 접근 허가를 받는지
* 어떠한 작업이 객체에 수행되도록 허가를 받을지

주로 ACL 은 네트워킹 개념으로 많이 사용되며, 라우터나 스위치에서 ACL 은 IP 주소와 포트 번호를 이용한 규칙을 가리킨다.
