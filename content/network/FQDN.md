# A) FQDN ?

도메인 이름의 절대 표기를 의미한다. FQDN 은 ‘ 절대 도메인 네임 ’ 또는 ‘ 전체 도메인 네임 ’ 이라고도 불리는 도메인 전체 이름을 표기하는 방식을 의미한다.

## A.1) 예시

`dkosv3-recoteam-cluster-v2-worker-6648.ay1.krane.9rum.cc`

# B) 그 외

FQDN 와 달리 전체 경로명이 아닌 하위 일부 경로만으로 식별 가능하게 하는 이름을 PQDN (Partially Qualified Domain Name) 라 한다.
