# stringstream(C++) ?

C++ 에서는 여러가지 자료형이 string 으로 한 줄에 들어오면 이것을 어떤 식으로 해야할지

고민하다가 stringstream 을 찾았는데, 한 줄에 들어오면 파싱해서 용도에 맞게 사용할 수 있었습니다.

`stringstream` 은 문자열에서 작동하는 스트림 클래스 입니다. 문자열에서 내가 원하는 자료형의 데이터를 추출할 때 사용합니다.

이 클래스 객체는 일련의 문자를 포함하는 문자열 버퍼를 사용하고 있습니다.
