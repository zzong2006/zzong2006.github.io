# A) Data Type of C++ ?

* `size_t`: 해당 시스템에서 어떤 객체나 값이 포함할 수 있는 최대 크기의 데이터를 표현하는 타입
	* 즉, x86 은 32 비트, x64 는 64 비트 변수가 됨
	* 반드시 unsigned 형
* `long (long int)`: a signed integer type with 32 bits
* `int64_t`: a signed integer type with 64 bits
* `vector`
