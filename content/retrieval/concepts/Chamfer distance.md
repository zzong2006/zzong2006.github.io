# A) Chamfer distance 개요

Chamfer distance(챔퍼 거리)는 두 포인트 집합(point cloud)이 얼마나 비슷한지 측정하는 지표다.

두 점 그룹 A, B 가 있을 때 Chamfer distance 는 다음처럼 계산한다.

1. 그룹 A 의 모든 점마다 그룹 B 에서 가장 가까운 점을 찾아, 그 거리를 모두 더한다.
2. 그룹 B 의 모든 점마다 그룹 A 에서 가장 가까운 점을 찾아, 그 거리를 모두 더한다.
3. 두 값을 더한 결과가 Chamfer distance 다.

이 거리가 작을수록 두 점 그룹이 더 비슷하다.

## A.1) 활용 분야

* **포인트 클라우드 정렬**: 두 개 이상의 포인트 클라우드를 정렬할 때 Chamfer distance 를 최소화해 최적의 정렬을 찾는다.
* **딥러닝 손실 함수**: 생성한 포인트 클라우드가 목표 포인트 클라우드와 최대한 비슷해지도록 Chamfer distance 를 손실 함수로 쓴다.
* **포인트 클라우드 완성**: 불완전한 포인트 클라우드를 완성하는 작업의 평가 지표로 쓴다.
	* 전체 구조와 국소적인 기하학적 디테일을 모두 반영해 평가한다.

## A.2) 한계

* Chamfer distance 는 점의 밀도 차이에 둔감하고, 특이점(outlier)의 영향을 많이 받는다.
* 이를 보완한 Density-aware Chamfer Distance (DCD) 같은 측정 방식도 제안되었다.

# B) 계산 예시

## B.1) 1차원 예시

1차원 점 그룹 A 와 B 가 있다.

* **그룹 A**: {1, 2, 3}
* **그룹 B**: {2, 4}

**1단계: 그룹 A 의 각 점에서 그룹 B 까지의 최단 거리**

* A 의 점 1 에서 가장 가까운 B 의 점은 2 다. 거리: |1 - 2| = 1
* A 의 점 2 에서 가장 가까운 B 의 점은 2 다. 거리: |2 - 2| = 0
* A 의 점 3 에서 가장 가까운 B 의 점은 2 또는 4 다. |3-2|=1, |3-4|=1 로 같으므로 거리는 1 이다.

**그룹 A -> 그룹 B 거리의 합**: 1 + 0 + 1 = 2

**2단계: 그룹 B 의 각 점에서 그룹 A 까지의 최단 거리**

* B 의 점 2 에서 가장 가까운 A 의 점은 2 다. 거리: |2 - 2| = 0
* B 의 점 4 에서 가장 가까운 A 의 점은 3 이다. 거리: |4 - 3| = 1

**그룹 B -> 그룹 A 거리의 합**: 0 + 1 = 1

**3단계: 두 거리의 합**

* **Chamfer Distance** = (그룹 A -> B 거리의 합) + (그룹 B -> A 거리의 합) = 2 + 1 = **3**

## B.2) 2차원 예시

2차원 평면에서 두 모양(파란색 별과 주황색 오각형)을 비교한다.

1. **파란색 별 → 주황색 오각형**: 파란색 별의 각 점에서 주황색 오각형의 가장 가까운 점까지의 거리(초록색 선)를 모두 더한다.
2. **주황색 오각형 → 파란색 별**: 반대로 주황색 오각형의 각 점에서 파란색 별의 가장 가까운 점까지의 거리(보라색 선)를 모두 더한다.

두 값의 합이 두 도형의 Chamfer distance 다.

* 이 값이 0 에 가까울수록 두 도형의 모양과 위치가 거의 일치한다.
* 두 도형이 완전히 같고 같은 위치에 있으면 Chamfer distance 는 0 이다.
