# A) Yelp Search Query Understanding with LLMs

Yelp 검색에서 LLM을 query understanding에 활용하는 흐름을 정리하기 위한 placeholder 노트다. Product search나 local search에서는 query rewriting, intent classification, entity extraction이 [[Cascade Ranking System]] 앞단의 candidate generation 품질을 크게 좌우한다.
