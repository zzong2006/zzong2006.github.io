# A) Probability Calibration ?

모델이 내놓은 확률값이 실제 발생 빈도와 맞도록 조정하는 작업이다. "확률 0.7 이라고 예측한 사례들을 모아 보면 실제로 그중 약 70% 가 양성" 이면 잘 보정된 것이다.

분류 정확도가 높은 것과 확률이 맞는 것은 다른 문제다. 모든 양성에 0.55, 모든 음성에 0.45 를 주는 모델은 정확도가 완벽해도 확률값은 쓸모없다. 반대로 순위는 잘 매기지만 값 자체는 한쪽으로 쏠린 모델도 흔하다.

# B) 언제 확률값이 필요한가

순위만 필요한 작업(검색 결과 정렬 등)에는 보정이 없어도 된다. 확률값을 다른 수와 곱하거나 임계값과 비교해야 할 때 문제가 된다.

- **광고 입찰**: 예상 클릭률 × 입찰가로 노출 한 번의 기대 수익을 계산한다
- **의사결정 임계값**: "확률 0.3 이상이면 검사한다" 같은 규칙은 0.3 이 실제 확률일 때만 뜻이 있다
- **모델 여러 개의 출력을 합칠 때**: 서로 다르게 치우친 확률을 평균 내거나 곱하면 결과가 왜곡된다

## B.1) 광고 경매에서 값이 틀리면 순위가 뒤집힌다

CPC 광고는 클릭이 일어날 때만 돈을 받는다. 그래서 어느 광고를 보여 줄지는 노출 한 번의 기대 수익 $\text{pCTR} \times \text{입찰가}$ 로 정한다. 1,000 번 노출 기준으로 바꾼 값이 [[eCPM]] 이다.

광고 두 개의 진짜 클릭률이 A 0.02, B 0.012 라고 하자.

| 광고 | 클릭당 입찰가 | 진짜 CTR | 진짜 기대 수익 | 모델 pCTR | 모델이 본 기대 수익 |
| --- | --- | --- | --- | --- | --- |
| A | 500 원 | 0.020 | 10 원 | 0.040 | 20 원 |
| B | 1,000 원 | 0.012 | 12 원 | 0.012 | 12 원 |

모델은 A 의 클릭률을 두 배로 부풀렸다. A 가 B 보다 클릭률이 높다는 **순서** 는 맞혔다. 그런데 값이 틀려서 경매에서는 A 가 이기고, 노출 한 번에 2 원씩 덜 번다.

순위만 보는 지표로는 이 모델의 문제를 찾을 수 없다. 클릭률이 A > B 라는 순서는 진짜 값과 같기 때문이다.

# C) AUC 는 순서만 본다

[[Area Under Curve|AUC]] 는 "양성 하나와 음성 하나를 뽑았을 때 양성 점수가 더 높을 확률" 이다. 점수의 크기는 보지 않고 대소 관계만 본다. 그래서 점수를 제곱하든, 두 배 하든, 순서를 유지하는 어떤 변환을 해도 AUC 는 그대로다.

AUC 가 높다는 것은 "잘 줄 세운다" 는 뜻이지 "확률값이 맞다" 는 뜻이 아니다. 확률값이 맞는지는 따로 측정한다.

| 측정 방법 | 보는 것 |
| --- | --- |
| reliability diagram | 예측을 구간으로 묶어, 구간마다 평균 예측과 실제 양성 비율을 점으로 찍는다. 대각선에 붙을수록 잘 보정된 것이다 |
| expected calibration error (ECE) | reliability diagram 의 대각선과의 차이를 구간 크기로 가중 평균한 값 |
| calibration ratio | 전체 평균 예측 ÷ 실제 양성 비율. 1 이면 총량이 맞는다. 광고에서는 예측 클릭 수 ÷ 실제 클릭 수로 본다 |
| log loss ([[cross-entropy]]) | 확률값 자체에 벌점을 준다. 보정이 틀어지면 AUC 는 그대로여도 log loss 는 나빠진다 |

calibration ratio 는 총량만 본다. 높은 예측은 부풀리고 낮은 예측은 깎아 평균이 맞는 모델도 1 이 나온다. 그래서 reliability diagram 으로 구간별 모양을 같이 본다.

![[img-263881cdd8.png]]

그림의 원래 예측(주황)은 값이 0 과 1 쪽으로 밀려 있다. 낮은 구간에서는 실제보다 낮게, 높은 구간에서는 실제보다 높게 말한다. isotonic regression 으로 보정하면(파랑) 점들이 대각선 위로 올라오고 ECE 가 0.082 에서 0.007 로 줄어든다. AUC 는 두 경우 모두 0.745 다.

# D) 무엇이 확률을 틀어지게 하나

[[logistic regression]] 은 손실 함수 자체가 확률을 맞추도록 되어 있어 비교적 잘 보정된 편이다. 반면 부스팅 계열은 마진을 키우는 방향으로 학습하다 보니 확률이 0 과 1 쪽으로 밀리고, 나이브 베이즈는 특징 간 독립 가정 때문에 극단으로 치우친다. 깊은 신경망은 학습 데이터를 거의 완전히 맞출 때까지 훈련하면서 과한 확신을 갖게 되는 쪽으로 알려져 있다.

## D.1) Negative downsampling 은 보정을 통째로 옮긴다

클릭률 모델은 음성(클릭 안 함)이 양성보다 수십에서 수백 배 많다. 학습 비용을 줄이려고 음성의 일부만 남기는 일이 흔한데, 그러면 모델이 본 양성 비율이 실제보다 커지고 예측도 그만큼 부풀려진다.

음성을 비율 $w$ 로만 남겨 학습했다면 예측 $p$ 를 아래처럼 되돌린다 (He et al., 2014).

$$
q = \frac{p}{p + (1 - p) / w}
$$

| 기호 | 의미 |
| --- | --- |
| $p$ | downsampling 한 데이터로 학습한 모델의 예측 |
| $w$ | 남긴 음성의 비율. 10% 만 남겼으면 0.1 |
| $q$ | 원래 데이터 분포 기준으로 되돌린 확률 |

음성을 10% 만 남긴 모델이 0.5 를 예측했다면, 실제 확률은 $0.5 / (0.5 + 0.5/0.1) \approx 0.091$ 이다. 이 변환은 순서를 바꾸지 않으므로 AUC 는 그대로이고 값만 바뀐다.

# E) 보정 방법

검증용 데이터를 따로 떼어 두고, 모델 출력을 실제 빈도에 맞추는 함수를 그 위에서 학습한다. 학습에 쓴 데이터로 보정하면 이미 과하게 맞춰진 출력을 기준으로 삼게 되어 의미가 없다.

| 방법 | 방식 | 순서 보존 |
| --- | --- | --- |
| Platt scaling | 모델 점수 $s$ 에 $\sigma(a s + b)$ 를 씌워 $a$, $b$ 두 파라미터만 학습한다. 데이터가 적을 때 안정적이다 | 지킨다 ($a > 0$ 일 때) |
| [[Isotonic Regression]] | 단조 증가만 지키는 계단 함수를 자유롭게 학습한다. 모양에 가정이 없는 대신 데이터가 적으면 과적합한다 | 지키지만 같은 계단 안의 점수는 동점이 된다 |
| temperature scaling | 신경망의 logit 을 스칼라 $T$ 로 나눈 뒤 [[softmax function]] 을 적용한다 | 지킨다 |

Platt scaling 은 S 자 모양 하나로만 고칠 수 있다. 원래 예측이 S 자가 아닌 모양으로 틀어져 있으면 다 못 고친다. isotonic regression 은 어떤 단조 모양이든 따라가지만, 계단이 생기면서 서로 다른 점수가 같은 확률이 되어 AUC 가 조금 바뀔 수 있다.

보정은 학습이 끝난 모델 뒤에 붙이는 후처리라 순위 모델을 다시 학습하지 않아도 된다. 다만 데이터 분포가 바뀌면 보정 함수도 다시 맞춰야 한다. 광고에서는 calibration ratio 를 매일 감시하다가 1 에서 벗어나면 보정 함수를 갱신한다.
