# A) Linear Probing ?

[[transfer learning]] 의 방식 중 하나로, head 레이어만 학습시키고 나머지 기존 모델의 weight 는 얼리는 접근 방법 중 하나다.

이 학습 방식과 다른 방식은 [[fine tuning]] 이 존재한다.
