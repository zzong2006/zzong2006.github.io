# A) Logistic Loss ?

[[logistic regression]] 에서 사용하는 [[cost function|loss function]] 을 의미한다.

## A.1) Logistic Loss Function 정의

$f\left(\mathbf{x}_{i}, \beta\right)$ 는 모델의 출력값이고 $y_{i}$ 는 true label 이라 한다면, logistic loss 는 다음과 같이 정의된다.

$$
\log \left(1+\exp \left(-y_{i} f\left(\mathbf{x}_{i}, \beta\right)\right)\right)
$$
