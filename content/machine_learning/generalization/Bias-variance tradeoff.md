# A) 예측 오차를 세 부분으로 나누기

모델이 새 데이터에서 틀리는 이유는 한 가지가 아니다. 모델의 형태가 단순해서 실제 관계를 담지 못할 수도 있고, 학습 데이터의 우연한 잡음까지 따라가서 틀릴 수도 있고, 데이터 자체에 아무도 맞힐 수 없는 잡음이 섞여 있을 수도 있다. 원인마다 고치는 방법이 다르므로, 오차를 원인별로 나눠 보는 것이 출발점이다.

## A.1) 분해 식

데이터가 참 함수 $f$ 에 잡음 $\varepsilon$ 이 더해져 만들어진다고 하자.

$$
y = f(x) + \varepsilon, \qquad \mathbb{E}[\varepsilon] = 0, \qquad \operatorname{Var}(\varepsilon) = \sigma_\varepsilon^2
$$

학습 데이터 $D$ 는 같은 분포에서 뽑을 때마다 달라지고, 그때마다 학습한 모델의 예측 $\hat f_D(x)$ 도 달라진다. 새 입력 $x$ 에서의 기대 제곱 오차는 세 항의 합으로 나뉜다.

$$
\mathbb{E}_{D,\,\varepsilon}\Big[\big(y - \hat f_D(x)\big)^2\Big]
= \underbrace{\big(\mathbb{E}_D[\hat f_D(x)] - f(x)\big)^2}_{\text{bias}^2}
+ \underbrace{\mathbb{E}_D\Big[\big(\hat f_D(x) - \mathbb{E}_D[\hat f_D(x)]\big)^2\Big]}_{\text{variance}}
+ \underbrace{\sigma_\varepsilon^2}_{\text{irreducible error}}
$$

| 기호 | 뜻 |
| --- | --- |
| $x$, $y$ | 새로 들어온 입력과 그 실제 값 |
| $f(x)$ | 데이터를 만들어낸 참 함수. 잡음 없는 값 |
| $\varepsilon$ | 데이터에 섞인 잡음. 평균 0, 분산 $\sigma_\varepsilon^2$ 이고 학습 데이터와 독립이다 |
| $D$ | 학습 데이터. 같은 분포에서 새로 뽑을 때마다 달라진다 |
| $\hat f_D(x)$ | 학습 데이터 $D$ 로 학습한 모델이 $x$ 에서 내는 예측 |
| $\mathbb{E}_D[\cdot]$ | 학습 데이터를 무한히 새로 뽑아 가며 낸 평균(기댓값) |

세 항은 각각 다음을 뜻한다.

- **[[bias]]²**: 학습 데이터를 바꿔 가며 학습한 예측들의 평균이 참값에서 벗어난 정도의 제곱이다. 데이터를 아무리 바꿔도 평균적으로 남는 치우침이라서, 모델의 형태가 실제 관계를 담지 못할 때 커진다. 휘어진 관계를 직선으로 맞추면 어떤 데이터로 학습해도 휘어진 부분을 놓친다.
- **[[variance]]**: 예측들이 자기 평균 주위로 흩어진 정도다. 학습 데이터가 바뀔 때 예측이 얼마나 흔들리는지를 나타내고, 모델이 학습 데이터의 잡음까지 따라갈 때 커진다.
- **irreducible error**: 관측값 $y$ 자체에 섞인 잡음의 분산이다. 참 함수 $f$ 를 정확히 알아서 $f(x)$ 로 예측해도 $y$ 와 $f(x)$ 는 $\varepsilon$ 만큼 다르다. 그래서 같은 입력 $x$ 를 쓰는 한 어떤 모델로도 줄일 수 없다. 이 잡음의 일부가 관측하지 않은 변수에서 온 것이라면 그 변수를 입력에 추가해 줄일 수 있지만, 그때는 입력이 바뀌어 $f$ 와 $\sigma_\varepsilon^2$ 가 모두 다른 문제가 된다.

모델을 고쳐서 줄일 수 있는 것은 bias² 와 variance 둘뿐이다.

![[img-aed6f30c72.jpg|img]]

과녁의 중심이 참값 $f(x)$ 이고, × 하나가 학습 데이터 하나로 학습한 모델의 예측이다. × 들의 무게중심이 중심에서 벗어난 정도가 bias, × 들이 서로 흩어진 정도가 variance 다.

## A.2) 분해가 성립하는 이유

$x$ 를 하나 고정하고, 예측의 평균을 $\bar f(x) = \mathbb{E}_D[\hat f_D(x)]$ 로 쓴다. 오차를 세 조각으로 나눈다.

$$
y - \hat f_D(x) = \underbrace{\big(f(x) - \bar f(x)\big)}_{a} + \underbrace{\big(\bar f(x) - \hat f_D(x)\big)}_{b} + \varepsilon
$$

양변을 제곱하고 $D$ 와 $\varepsilon$ 에 대해 기댓값을 취하면, 제곱항 세 개와 곱항 세 개가 나온다.

- 제곱항: $a$ 는 $D$ 와 무관한 상수라서 $\mathbb{E}[a^2] = a^2$ 이 bias² 다. $\mathbb{E}[b^2]$ 는 정의 그대로 variance, $\mathbb{E}[\varepsilon^2] = \sigma_\varepsilon^2$ 이다.
- $2\,\mathbb{E}[ab] = 2a\,\mathbb{E}_D[b] = 0$ 이다. $\bar f$ 가 $\hat f_D$ 의 평균이므로 $b$ 의 평균은 0 이다.
- $2\,\mathbb{E}[a\varepsilon] = 2a\,\mathbb{E}[\varepsilon] = 0$ 이다.
- $2\,\mathbb{E}[b\varepsilon] = 2\,\mathbb{E}_D[b]\,\mathbb{E}[\varepsilon] = 0$ 이다. 새 데이터의 잡음 $\varepsilon$ 은 학습 데이터 $D$ 와 독립이라 기댓값을 따로 계산할 수 있다.

곱항이 모두 0 이므로 세 제곱항의 합만 남는다. 이 유도는 제곱 오차에서만 이렇게 깔끔하게 나뉜다. 0-1 loss 같은 분류 오차에는 같은 꼴의 분해가 성립하지 않는다.

## A.3) 숫자로 보기

[[overfitting]] 노트의 다항식 예제는 참 함수 $\sin(2\pi x)$ 에 표준편차 0.3 인 잡음을 넣어 점 10 개를 만들고, 다항식을 맞추는 실험을 1,000 번 반복했다. $x = 0.95$ 에서 세 항을 계산하면 다음과 같다.

| 모델 | bias² | variance | irreducible error | 합 (기대 제곱 오차) |
| --- | --- | --- | --- | --- |
| 1 차 직선 | 0.09 | 0.03 | 0.09 | 0.21 |
| 9 차 다항식 | 0.0001 | 3.96 | 0.09 | 4.05 |

1 차 직선은 어떤 데이터로 학습해도 비슷한 직선이 나오지만(variance 0.03), 그 직선들이 평균적으로 참값에서 벗어나 있다(bias² 0.09). 9 차 다항식은 평균으로는 참값을 거의 맞히지만, 학습 데이터마다 곡선이 크게 출렁여서 variance 가 3.96 이다. 두 모델 모두 잡음 몫 0.09 는 그대로 남는다.

# B) 한쪽을 줄이면 다른 쪽이 늘어난다

모델이 표현할 수 있는 함수의 범위를 capacity 라고 한다. capacity 를 키우면 모델이 실제 관계를 더 잘 담을 수 있어 bias 가 줄어든다. 동시에 학습 데이터의 잡음까지 따라갈 여유도 생겨 variance 가 늘어난다. 앞 예제에서 직선을 9 차 다항식으로 바꾸자 bias² 는 0.09 에서 0.0001 로 줄고 variance 는 0.03 에서 3.96 으로 늘었다.

![[img-7897583563.png|image-20201028202552847]]

분류에서도 같다. 왼쪽의 직선 경계는 ○ 와 × 를 가르는 휘어진 경계를 담지 못한다(high bias). 오른쪽 경계는 학습 데이터의 점 하나하나를 피해 가도록 구불구불하게 휘어서, 학습 데이터가 조금만 바뀌어도 모양이 크게 달라진다(high variance). 가운데가 둘 사이의 균형점이다.

capacity 를 키워 가면 test 오차는 처음에 bias 가 줄면서 내려가다가, 어느 지점부터 variance 가 늘면서 다시 올라간다. 두 항의 합이 가장 작은 지점의 capacity 를 고르는 것이 이 trade-off 의 실무적인 의미다.

다만 이 U 자 모양이 모든 경우에 성립하지는 않는다. 파라미터가 학습 샘플보다 훨씬 많은 신경망은 학습 데이터를 다 외울 수 있는데도 새 데이터에서 잘 맞히고, 모델을 더 키우면 test 오차가 다시 내려가는 [[double descent]] 도 관찰된다. 데이터가 충분히 많으면 큰 모델로 bias 와 variance 를 함께 줄일 수도 있다. 이 경우는 overfitting 노트의 "파라미터가 데이터보다 많아도 일반화하는 경우" 절에서 다룬다.

# C) 학습 오차와 검증 오차로 진단한다

bias 와 variance 는 학습 데이터를 여러 번 새로 뽑아야 잴 수 있다. 실제로는 학습 데이터가 하나뿐이므로, 학습 오차와 검증 오차를 나란히 놓고 대략 추정한다.

추정에는 기준 오차가 필요하다. 기준 오차는 그 문제에서 어떤 모델로도 더 내려갈 수 없는 오차, 즉 irreducible error 에 해당하는 값이다. 실제로는 이 값을 알 수 없어서 사람의 오류율을 대신 쓰는 경우가 많다. 기준이 정해지면 두 차이를 본다.

$$
\text{bias 의 추정} \approx E_{\text{train}} - E_{\text{base}}, \qquad \text{variance 의 추정} \approx E_{\text{val}} - E_{\text{train}}
$$

| 기호 | 뜻 |
| --- | --- |
| $E_{\text{base}}$ | 기준 오차. 사람의 오류율 같은, 도달할 수 있는 가장 낮은 오차의 추정 |
| $E_{\text{train}}$ | 학습 데이터에서의 오차 |
| $E_{\text{val}}$ | 학습에 쓰지 않은 검증 데이터에서의 오차 |

학습 오차가 기준보다 많이 높으면, 모델이 학습 데이터조차 맞추지 못하는 것이므로 bias 가 크다. 검증 오차가 학습 오차보다 많이 높으면, 학습 데이터에만 맞고 새 데이터에는 맞지 않는 것이므로 variance 가 크다. 두 식은 분해 식의 항을 정확히 계산한 값이 아니라 어느 쪽이 문제인지 가리는 어림값이다. 학습 데이터와 검증 데이터의 분포가 다르면 그 차이도 둘째 식에 섞여 들어간다.

사람이 거의 틀리지 않는 선명한 고양이 사진 분류라면 기준 오차는 0% 에 가깝다. 이때 오차 조합별 판정은 다음과 같다.

| 학습 오차 | 검증 오차 | 판정 | 근거 |
| --- | --- | --- | --- |
| 1% | 11% | high variance | 학습 오차는 기준에 가깝고, 검증 오차가 10%p 높다 |
| 15% | 16% | high bias | 학습 오차부터 기준보다 15%p 높고, 검증과의 차이는 1%p 다 |
| 15% | 30% | high bias, high variance | 학습 오차가 기준보다 15%p, 검증 오차가 학습보다 15%p 높다 |
| 1% | 2% | low bias, low variance | 두 오차 모두 기준에 가깝다 |

같은 숫자라도 기준이 바뀌면 판정이 바뀐다. 사진이 흐려서 사람도 15% 를 틀리는 문제라면, 학습 오차 15%·검증 오차 16% 는 bias 가 큰 것이 아니라 기준에 이미 도달한 상태다.

학습 데이터 양을 바꿔 가며 두 오차를 그린 학습 곡선은 이 진단을 더 분명하게 해 준다. 그리는 방법은 overfitting 노트의 "학습 곡선으로 원인을 좁힌다" 절에 있다.

# D) 원인에 따라 처방이 다르다

## D.1) variance 가 클 때: 정규화부터

variance 가 크다는 것은 모델이 학습 데이터의 잡음까지 따라갈 여유가 있다는 뜻이다. 처방은 모두 그 여유를 줄이는 쪽이다.

가장 먼저 시도하는 것은 [[regularization]] (정규화)다. 지금 모델과 데이터를 그대로 두고, 강도를 정하는 값 하나를 검증 오차를 보며 조절하면 된다. 데이터를 더 모으는 것은 비용이 들고, 모델을 작게 바꾸는 것은 구조를 다시 설계해야 한다.

- **L2 / L1 벌점**: 학습이 최소화하는 목적 함수에 가중치 크기에 대한 벌점을 더한다. L2 는 가중치 제곱의 합, L1 은 절댓값의 합에 벌점을 준다. L2 는 모든 가중치를 고르게 작게 만들고, L1 은 일부 가중치를 정확히 0 으로 만들어 feature 를 고르는 효과도 낸다 ([[ridge regression]], [[lasso regression]]).
- **[[dropout]]**: 신경망 학습 중 매 step 무작위로 고른 unit 의 출력을 0 으로 만든다. 특정 unit 들의 조합에만 기대는 표현을 만들기 어려워진다.
- **[[Early Stopping]]**: epoch 마다 검증 오차를 보다가 더 내려가지 않으면 학습을 멈춘다. 학습이 길어질수록 모델이 잡음까지 맞추므로, 학습 시간 자체를 제한하는 셈이다.

큰 가중치에 벌점을 주는 것이 왜 variance 를 줄이는지는 overfitting 노트의 "큰 가중치에 벌점을 준다" 절이 9 차 다항식으로 계산해 보인다. 같은 9 차 다항식에서 L2 벌점의 강도만 $10^{-4}$ 로 주자 test RMSE 가 0.73 에서 0.36 으로 내려갔다.

정규화로 부족하면 다음을 고려한다.

- **데이터를 늘린다.** 같은 모델이라도 데이터가 많아지면 잡음을 외울 여유가 사라진다. 효과는 가장 확실하지만 비용이 든다.
- **모델을 작게 만든다.** 층이나 unit 수, 트리 깊이, feature 수를 줄인다.
- **[[bagging]] 으로 여러 모델을 평균한다.** D.3 에서 다룬다.

정규화를 너무 세게 주면 이번에는 실제 관계까지 맞추지 못해 bias 가 커진다. 강도는 항상 검증 오차로 정한다.

## D.2) bias 가 클 때: 표현력을 늘린다

bias 가 크다는 것은 모델의 형태가 실제 관계를 담지 못한다는 뜻이다. 이때는 데이터를 늘려도 소용이 없다. 직선은 데이터가 백만 개여도 직선이다.

- 모델을 키운다. 층이나 unit 수를 늘리거나 더 유연한 모델로 바꾼다.
- feature 를 추가한다. 다항 항, 상호작용 항, 도메인 지식으로 만든 변수를 넣는다.
- 정규화를 줄인다. 벌점이 너무 세서 bias 가 생긴 경우다.
- 더 오래 학습한다. 아직 수렴하지 않은 것과 표현력이 부족한 것은 다르므로, 학습 곡선이 아직 내려가는 중인지 먼저 본다.
- boosting 으로 단순한 모델을 차례로 더한다. 바로 다음 절에서 다룬다.

자세한 내용은 [[underfitting]] 노트에 있다.

## D.3) 앙상블: bagging 은 variance 를, boosting 은 bias 를 줄인다

여러 모델의 예측을 합치는 [[ensemble]] 도 어느 항을 줄이는지가 방법마다 다르다.

**[[bagging]]** 은 학습 데이터에서 복원추출로 표본 $B$ 개를 만들고, 표본마다 모델을 따로 학습해 예측을 평균한다. 같은 방식으로 학습한 모델들의 평균이므로 평균의 기댓값은 모델 하나의 기댓값과 같고, bias 는 그대로다. 반면 흔들림은 평균하면서 상쇄된다. 모델 하나의 분산을 $\sigma^2$, 두 모델 예측 사이의 상관을 $\rho$ 라고 하면 평균의 분산은 다음과 같다.

$$
\operatorname{Var}\Big(\frac{1}{B}\sum_{b=1}^{B} \hat f_b(x)\Big) = \rho\,\sigma^2 + \frac{1-\rho}{B}\,\sigma^2
$$

| 기호 | 뜻 |
| --- | --- |
| $\hat f_b(x)$ | $b$ 번째 bootstrap 표본으로 학습한 모델의 예측 |
| $B$ | 평균하는 모델 수 |
| $\sigma^2$ | 모델 하나의 예측 분산 (variance) |
| $\rho$ | 서로 다른 두 모델 예측 사이의 상관계수 |

모델 수 $B$ 를 늘리면 둘째 항만 0 으로 가고, 첫째 항 $\rho\sigma^2$ 는 남는다. 표본들이 모두 같은 학습 데이터에서 나와 모델끼리 닮아 있기 때문이다. [[random forest]] 는 분할마다 쓸 feature 를 무작위로 골라 $\rho$ 를 낮춘다. 그래서 bagging 은 깊은 decision tree 처럼 bias 가 작고 variance 가 큰 모델과 잘 맞는다. bagging 노트의 실험에서 깊은 나무 하나를 나무 100 개의 bagging 으로 바꾸자 bias² 는 0 에 가까운 채로 variance 가 0.095 에서 0.046 으로 절반이 됐다.

**[[boosting]]** 은 모델을 하나씩 차례로 더한다. 새 모델은 지금까지의 앙상블이 틀린 부분(회귀에서는 남은 오차)을 맞추도록 학습하고, learning rate 를 곱해 앙상블에 더해진다. 하나하나는 깊이 1 나무처럼 단순해서 bias 가 큰 모델이지만, 앞의 모델이 틀린 구간을 다음 모델이 고쳐 나가므로 합쳐진 예측은 점점 복잡한 함수를 표현한다. 그래서 줄어드는 것은 주로 bias 다.

모델을 계속 더하면 남은 오차가 잡음뿐인 구간까지 맞추기 시작해 variance 가 늘어난다. 앞의 bagging 실험과 같은 데이터(참 함수 $\sin(2\pi x)$, 잡음 표준편차 0.3, 학습 점 50 개)로 깊이 1 나무를 learning rate 0.1 로 더해 가며, 학습 데이터를 300 번 새로 뽑아 잰 결과는 다음과 같다. bias² 와 variance 는 0–1 구간의 200 곳에서 재어 평균했다.

| 더한 나무 수 | 학습 RMSE | test RMSE | bias² | variance |
| --- | --- | --- | --- | --- |
| 1 | 0.706 | 0.723 | 0.420 | 0.010 |
| 10 | 0.449 | 0.478 | 0.129 | 0.010 |
| 100 | 0.250 | 0.351 | 0.010 | 0.024 |
| 1,000 | 0.164 | 0.364 | 0.001 | 0.042 |
| 3,000 | 0.113 | 0.382 | 0.001 | 0.056 |

나무 1 개일 때 bias² 가 큰 것은 learning rate 0.1 때문에 첫 나무 예측의 10% 만 반영됐기 때문이다. 나무를 100 개까지 더하는 동안 bias² 는 0.420 에서 0.010 으로 줄고, test RMSE 도 가장 낮아진다. 그 뒤로는 bias² 가 더 줄 것이 없는데 variance 만 0.024 에서 0.056 으로 늘어 test RMSE 가 다시 오른다. 학습 RMSE 는 그동안에도 계속 내려간다. 그래서 boosting 은 더할 모델 수를 검증 오차로 정하고, learning rate 를 작게 하거나 early stopping 을 함께 쓴다. bagging 은 모델 수를 늘려도 test 오차가 다시 오르지 않는다는 점과 다르다.

| 기준 | bagging | boosting |
| --- | --- | --- |
| 주로 줄이는 항 | variance | bias |
| 잘 맞는 기본 모델 | bias 가 작고 variance 가 큰 모델 (깊은 나무) | variance 가 작고 bias 가 큰 모델 (얕은 나무) |
| 모델을 학습하는 순서 | 서로 독립, 동시에 학습 | 앞 모델이 남긴 오차를 보고 차례로 학습 |
| 모델 수를 늘리면 | test 오차가 바닥값으로 수렴 | 너무 많으면 variance 가 늘어 test 오차가 다시 오른다 |

두 방법의 학습 방식과 수치 비교는 bagging 노트의 "Bagging 과 boosting 은 줄이는 오차가 다르다" 절에 더 자세히 있다.
