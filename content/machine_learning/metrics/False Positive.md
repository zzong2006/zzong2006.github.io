# A) False Positive ?

실제 음성 (negative) 인 데이터를 (통계) 모델이 양성 (positive) 으로 판정해서 발생하는 오류

* 실제: negative (False)
* 예측: positive

[[null hypothesis|귀무가설]] 이 실제로 참이지만, 귀무가설을 기각하는 오류이다.

$\alpha$ Error 라고도 불린다. Type 1 error 의 0.05 및 5% 의 유의수준은 귀무 가설이 5% 확률로 잘못 기각될 수 있다는 의미를 가진다.
