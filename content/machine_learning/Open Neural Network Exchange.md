# A) Open Neural Network Exchange ?

ONNX is an open format built to represent machine learning models.

AI tool 을 통해 개발을 진행하는 경우 종종 한가지 프레임워크에 갇혀있는 경우가 많다. ONNX 를 이용하면 서로간 모델을 공유할 수 있다.
