# A) Tagging ?

레포지토리의 히스토리 중 어느 특정 지점에 영구적으로 tag 를 작성하는 것

## A.1) Tagging a Release

tagging 된 상태에서 레포지토리의 모든 파일들을 다운로드 가능한 release 상태로 만드는 것

# B) 예시

```bash
git tag v0.1.0   # tag 생성
git push --tags  # tag push
```
