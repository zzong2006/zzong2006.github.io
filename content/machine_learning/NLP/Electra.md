# A) Electra ?

ICLR 2020 에서 구글 리서치 팀은 새로운 pre-training 기법을 적용한 language model, **ELECTRA** (**E**fficiently **L**earning an **E**ncoder that **C**lassifies **T**oken **R**eplacements **A**ccurately) 를 발표

기존 [[Bidirectional Encoder Representations from Transformers|BERT]] 에서 masked language modeling 방식에서, 학습 효율을 향상시키기 위해 **Replaced Token Detection (RTD)**이라는 새로운 pre-training 태스크를 제안
