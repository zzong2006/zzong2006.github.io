# A) 여러 표본으로 학습한 모델의 예측을 평균한다

Bagging(bootstrap aggregating)은 학습 데이터에서 무작위로 다시 뽑은 표본을 여러 개 만들고, 표본마다 모델을 따로 학습한 뒤 그 예측을 평균하는 방법이다. [Breiman (1996)](https://link.springer.com/article/10.1007/BF00058655) 이 제안했고, [[random forest]] 의 바탕이 된다. 여러 모델의 예측을 합쳐 하나의 예측을 만드는 방법을 통틀어 [[ensemble]] 이라고 하는데, bagging 은 그중 가장 단순한 형태다.

## A.1) 학습 데이터가 바뀔 때 흔들리는 예측을 평균으로 줄인다

[[Decision Tree]] 같은 모델은 학습 데이터를 조금만 바꿔도 예측이 크게 달라진다. 나무의 첫 분할 위치가 바뀌면 그 아래 구조가 통째로 바뀌기 때문이다.

이 흔들림을 재는 방법은 다음과 같다. 같은 분포에서 학습 데이터를 여러 번 새로 뽑아, 뽑을 때마다 모델을 다시 학습한다. 그리고 한 입력 $x$ 에서의 예측값을 모은다.

- 모은 예측값들의 평균이 참값에서 벗어난 정도를 **bias** 라고 한다.
- 모은 예측값들이 자기 평균 주위로 흩어진 정도(분산)를 **variance** 라고 한다.

데이터가 $y = f(x) + \varepsilon$ 으로 만들어진다고 하자. 학습 데이터 $D$ 로 학습한 모델의 예측을 $\hat f_D(x)$ 라고 쓰면, 두 값은 다음과 같다.

$$
\operatorname{Bias}(x) = \mathbb{E}_D\big[\hat f_D(x)\big] - f(x)
$$

$$
\operatorname{Var}(x) = \mathbb{E}_D\Big[\big(\hat f_D(x) - \mathbb{E}_D[\hat f_D(x)]\big)^2\Big]
$$

새 데이터에서의 기대 제곱 오차는 이 둘과 잡음의 분산으로 나뉜다 ([[Bias-variance tradeoff]]).

$$
\mathbb{E}_{D,\,\varepsilon}\Big[\big(y - \hat f_D(x)\big)^2\Big] = \operatorname{Bias}(x)^2 + \operatorname{Var}(x) + \sigma_\varepsilon^2
$$

| 기호 | 뜻 |
| --- | --- |
| $x$, $y$ | 새로 들어온 입력과 그 실제 값 |
| $f(x)$ | 데이터를 만들어낸 참 함수. 잡음 없는 값 |
| $\varepsilon$ | 데이터에 섞인 잡음. 평균 0, 분산 $\sigma_\varepsilon^2$ |
| $D$ | 학습 데이터. 같은 분포에서 새로 뽑을 때마다 달라진다 |
| $\hat f_D(x)$ | 학습 데이터 $D$ 로 학습한 모델이 $x$ 에서 내는 예측 |
| $\mathbb{E}_D[\cdot]$ | 학습 데이터를 무한히 새로 뽑아 가며 낸 평균(기댓값) |

$\sigma_\varepsilon^2$ 은 참 함수 $f$ 를 정확히 알아도 남는 오차라서 모델로 줄일 수 없다. 모델이 줄일 수 있는 것은 $\operatorname{Bias}^2$ 과 $\operatorname{Var}$ 이다. 학습 데이터의 잡음까지 따라가서 $\operatorname{Var}$ 이 커진 상태가 [[overfitting]] 이다.

학습 데이터를 $B$ 번 따로 뽑을 수 있다고 해 보자. 서로 독립인 학습 데이터 $D_1, \dots, D_B$ 로 모델 $B$ 개를 만들고 예측을 평균한다.

$$
\bar f(x) = \frac{1}{B}\sum_{b=1}^{B} \hat f_{D_b}(x)
$$

이 평균에 대해 다음 두 식이 성립한다.

$$
\mathbb{E}\big[\bar f(x)\big] = \mathbb{E}_D\big[\hat f_D(x)\big], \qquad \operatorname{Var}\big(\bar f(x)\big) = \frac{\operatorname{Var}(x)}{B}
$$

- 첫 식: 평균의 기댓값은 모델 하나의 기댓값과 같다. 그래서 bias 는 그대로다.
- 둘째 식: 서로 독립인 값 $B$ 개를 평균하면 분산이 $1/B$ 로 준다. 그래서 variance 가 $1/B$ 로 준다.

실제로는 학습 데이터가 하나뿐이다. bagging 은 그 하나에서 표본을 다시 뽑아 "따로 뽑은 학습 데이터" 를 흉내 낸다. 다시 뽑은 표본들은 모두 같은 학습 데이터에서 나오므로 서로 독립이 아니다. 그래서 실제로 줄어드는 폭은 $1/B$ 보다 작다. 얼마나 작은지는 뒤의 [[#평균하는 모델끼리 상관이 있으면 variance 가 바닥에서 멈춘다|평균하는 모델끼리 상관이 있으면 variance 가 바닥에서 멈춘다]] 절에서 계산한다.

## A.2) 절차

학습 데이터에 샘플이 $N$ 개 있을 때 다음과 같이 한다.

1. 학습 데이터에서 샘플 하나를 무작위로 뽑아 기록하고 다시 돌려놓는다. 이것을 $N$ 번 반복해 크기 $N$ 인 표본을 만든다. 이 표본을 **bootstrap 표본** 이라고 한다 ([[bootstrapping]]).
2. 1 을 $B$ 번 반복해 bootstrap 표본 $B$ 개를 만든다.
3. 각 bootstrap 표본으로 같은 종류의 모델을 하나씩 따로 학습한다. 모델끼리 서로의 결과를 쓰지 않으므로 동시에 학습할 수 있다.
4. 새 입력이 들어오면 $B$ 개 모델이 각자 예측한다.
	- 회귀: $B$ 개 예측값의 평균을 최종 예측으로 쓴다.
	- 분류: 가장 많은 모델이 고른 클래스를 쓰거나(다수결), 각 모델이 낸 클래스별 확률을 평균해 가장 높은 클래스를 쓴다.

# B) Bootstrap 표본에는 원래 샘플의 약 63% 가 들어간다

bootstrap 표본을 만들 때처럼 뽑은 것을 돌려놓고 다시 뽑는 방식을 **복원추출** 이라고 한다. 복원추출에서는 같은 샘플이 여러 번 뽑힐 수 있고, 한 번도 뽑히지 않는 샘플도 생긴다. 예를 들어 샘플 1–5 에서 다섯 번 뽑아 2, 5, 2, 1, 2 가 나왔다면, 2 번은 세 번 들어가고 3 번과 4 번은 빠진다.

특정 샘플 하나가 bootstrap 표본에서 빠질 확률은 다음과 같이 계산한다.

1. 한 번 뽑을 때 그 샘플이 뽑히지 않을 확률은 $1 - 1/N$ 이다.
2. $N$ 번의 뽑기는 서로 독립이므로, $N$ 번 내내 뽑히지 않을 확률은 이 값을 $N$ 번 곱한 것이다.

$$
P(\text{샘플 } i \text{ 가 빠짐}) = \left(1 - \frac{1}{N}\right)^N \;\longrightarrow\; e^{-1} \approx 0.368 \quad (N \to \infty)
$$

| 기호 | 뜻 |
| --- | --- |
| $N$ | 원래 학습 데이터의 샘플 수이자, bootstrap 표본의 크기 |
| $i$ | 원래 학습 데이터에서 특정 샘플 하나의 번호 |
| $e$ | 자연상수 2.718… |

| $N$ | 빠질 확률 | 표본에 한 번 이상 들어갈 확률 |
| --- | --- | --- |
| 5 | $0.8^5 = 0.328$ | 67.2% |
| 50 | $0.98^{50} = 0.364$ | 63.6% |
| 무한대 | $e^{-1} = 0.368$ | 63.2% |

뒤의 예제에서 $N = 50$ 으로 bootstrap 표본을 20 만 번 만들어 서로 다른 샘플의 비율을 세어 보면 평균 63.6% 였다. 계산과 같다.

여러 번 뽑힌 샘플은 그 횟수만큼 학습에 반영된다. 회귀 나무가 구간의 평균을 낼 때나 최소제곱법이 오차 제곱을 더할 때, 세 번 뽑힌 샘플은 세 번 더해진다. 그래서 bootstrap 표본은 원래 샘플에 0, 1, 2, … 의 무작위 가중치를 붙인 것과 같다. 표본마다 이 가중치가 다르므로 표본마다 다른 모델이 나온다.

표본에서 빠진 약 37% 의 샘플은 그 모델이 학습 때 보지 못한 데이터다. 이 샘플들로 별도 검증 데이터 없이 test 오차를 추정할 수 있다. 뒤의 [[#Out-of-bag 샘플로 검증 데이터 없이 test 오차를 추정한다|Out-of-bag 샘플로 검증 데이터 없이 test 오차를 추정한다]] 절에서 다룬다.

# C) 깊은 decision tree 를 bagging 하면 variance 가 절반으로 준다

이 절의 실험은 [[#학습 데이터가 바뀔 때 흔들리는 예측을 평균으로 줄인다|도입부]]의 주장, 즉 bagging 이 bias 는 그대로 두고 variance 만 줄인다는 것을 실제 값으로 확인한다. 아래 수치는 모두 직접 돌린 시뮬레이션 결과다. 설정과 측정 방법은 [[#부록 실험 방법과 전체 수치|부록]]에 있다.

[[overfitting]] 노트의 다항식 예제와 같은 참 함수 $y = \sin(2\pi x)$ 와 잡음(표준편차 0.3)으로 학습 점 50 개를 만들고, 두 모델을 비교했다.

- **깊은 나무 하나**: 학습 데이터 전체로 학습한 회귀 나무 하나.
- **bagging**: bootstrap 표본 100 개로 깊은 회귀 나무를 하나씩 학습하고 예측을 평균한 것.

회귀 나무는 $x$ 축을 여러 구간으로 나누고, 각 구간(**leaf**)의 예측값을 그 구간에 들어온 학습 샘플 $y$ 의 평균으로 둔다. "깊은" 나무는 leaf 마다 학습 샘플이 하나만 남을 때까지 나눈 나무다. 그래서 각 학습 샘플의 $y$ 를 그대로 예측하고 학습 오차가 0 이다. 9 차 다항식이 점 10 개를 모두 지난 것과 같은 상태다.

![[img-790db3a4a2.png]]

초록 곡선이 참 함수, 파란 원이 학습 데이터, 빨간 선이 예측이다.

- **위 두 그림** 은 같은 학습 데이터 하나로 만든 예측이다. 나무 하나(왼쪽)는 잡음 때문에 튄 점까지 계단으로 따라간다. $x = 0.6$ 근처에서 $-1.2$ 까지 꺾여 내려간 계단이 그런 점 하나를 따라간 결과다. bagging(오른쪽)에서는 튄 점이 bootstrap 표본의 약 37% 에서 빠지므로, 그 점을 따라간 계단이 나무 일부에만 생기고 평균에서 희석된다.
- **아래 두 그림** 은 학습 데이터를 20 번 새로 뽑아 만든 예측 20 개를 겹친 것이다. 나무 하나는 학습 데이터가 바뀔 때마다 예측이 크게 달라져 띠가 넓고, bagging 은 띠가 좁다. 이 띠의 폭이 variance 다.

같은 실험을 1,000 번 반복해 평균한 값은 다음과 같다. RMSE 는 오차 제곱의 평균에 제곱근을 씌운 값 $\sqrt{\tfrac{1}{n}\sum_i (y_i - \hat y_i)^2}$ 으로 $y$ 와 같은 단위다.

| 모델 | 학습 RMSE | test RMSE | bias² | variance |
| --- | --- | --- | --- | --- |
| 깊은 나무 하나 | 0.000 | 0.429 | 0.0003 | 0.095 |
| bagging (나무 100 개) | 0.136 | 0.369 | 0.0009 | 0.046 |

- **test RMSE 가 줄어든 것은 거의 전부 variance 몫이다.** variance 가 0.095 에서 0.046 으로 절반이 됐고, bias² 는 두 모델 모두 0 에 가깝다. 깊은 나무는 원래 bias 가 작고 variance 가 큰 모델이다.
- **분해 식이 그대로 맞는다.** 잡음 분산 $\sigma_\varepsilon^2 = 0.3^2 = 0.09$ 를 더하면 $0.0003 + 0.095 + 0.09 = 0.185$, $0.0009 + 0.046 + 0.09 = 0.137$ 이고, 제곱근이 0.430 과 0.369 로 test RMSE 와 맞는다. 잡음 몫 0.09 때문에 어떤 모델도 test RMSE 0.3 아래로는 갈 수 없다.
- **bagging 의 학습 RMSE 는 0 이 아니다.** 각 학습 샘플은 나무 100 개 중 약 37 개의 bootstrap 표본에서 빠지고, 그 나무들은 그 샘플을 주변 샘플로 예측하기 때문이다.

남는 질문은 나무 100 개를 평균했는데 왜 variance 가 $1/100$ 이 아니라 절반으로만 줄었느냐다. [[#평균하는 모델끼리 상관이 있으면 variance 가 바닥에서 멈춘다|다음 절]]에서 계산한다.

# D) 평균하는 모델끼리 상관이 있으면 variance 가 바닥에서 멈춘다

## D.1) 상관된 값 B 개를 평균한 분산

입력 $x$ 하나를 고정하고, $b$ 번째 나무의 그 위치 예측을 $T_b$ 라고 하자. $T_b$ 는 무작위 값이다. 학습 데이터를 무엇으로 뽑았는지, 그 학습 데이터에서 bootstrap 표본을 무엇으로 뽑았는지에 따라 달라지기 때문이다.

| 기호 | 뜻 |
| --- | --- |
| $T_b$ | $b$ 번째 bootstrap 나무가 고정된 입력 $x$ 에서 내는 예측값 |
| $B$ | 평균하는 나무의 수 |
| $\sigma^2$ | 나무 하나의 예측값 $T_b$ 의 분산. 학습 데이터 뽑기와 bootstrap 뽑기 양쪽의 무작위성을 다 포함한다. 잡음의 분산 $\sigma_\varepsilon^2$ 과는 다른 값이다 |
| $\operatorname{Cov}(T_b, T_{b'})$ | 두 나무 예측의 공분산. 두 값이 각자의 평균보다 함께 크거나 함께 작은 경향이 강할수록 큰 양수가 된다 |
| $\rho$ | 같은 학습 데이터에서 만든 서로 다른 두 나무 $T_b$, $T_{b'}$ 의 상관계수. 공분산을 두 표준편차의 곱(여기서는 $\sigma^2$)으로 나눈 값으로, 0 이면 서로 무관하고 1 이면 늘 같은 값을 낸다 |

모든 나무가 같은 방식으로 만들어지므로 $\sigma^2$ 와 $\rho$ 는 나무마다 같다. 평균의 분산은 다음 순서로 계산한다.

1. 합의 분산은 각 항의 분산을 모두 더하고, 서로 다른 두 항의 공분산을 모든 짝에 대해 더한 것이다.
2. 분산 항은 $B$ 개이고 각각 $\sigma^2$ 다.
3. 서로 다른 두 나무의 짝은 순서를 따져 $B(B-1)$ 개이고, 각 공분산은 상관계수의 정의에 따라 $\rho\sigma^2$ 다.
4. 평균은 합을 $B$ 로 나눈 것이므로 분산은 $1/B^2$ 배가 된다.

$$
\begin{aligned}
\operatorname{Var}\left(\frac{1}{B}\sum_{b=1}^{B} T_b\right)
&= \frac{1}{B^2}\left[\sum_{b} \operatorname{Var}(T_b) + \sum_{b \neq b'} \operatorname{Cov}(T_b, T_{b'})\right] \\
&= \frac{1}{B^2}\left[B\sigma^2 + B(B-1)\rho\sigma^2\right] \\
&= \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2
\end{aligned}
$$

[Hastie, Tibshirani, Friedman (2009)](https://hastie.su.domains/ElemStatLearn/) 의 식 15.1 과 같다. 두 항의 뜻은 다음과 같다.

- **둘째 항** $(1-\rho)\sigma^2/B$ 는 나무를 늘리면 0 으로 간다. 같은 학습 데이터 안에서 bootstrap 표본이 달라서 생기는 흔들림이다.
- **첫째 항** $\rho\sigma^2$ 는 $B$ 와 상관없이 남는다. 모든 나무가 같은 학습 데이터에서 나왔기 때문에 함께 흔들리는 몫이다. 학습 데이터가 우연히 어떤 잡음을 담고 있으면, 그 잡음은 거의 모든 bootstrap 표본에 들어가고 모든 나무가 같은 방향으로 따라간다.

$\rho = 0$ 이면 [[#학습 데이터가 바뀔 때 흔들리는 예측을 평균으로 줄인다|도입부]]의 "학습 데이터를 B 번 따로 뽑는" 이상적인 경우가 되어 분산이 $\sigma^2/B$ 다. $\rho = 1$ 이면 평균해도 분산이 $\sigma^2$ 그대로다.

## D.2) 예제의 나무들은 상관이 0.43 이라 variance 가 절반에서 멈춘다

이 실험은 두 가지를 확인한다. 위 식이 실제 나무에도 맞는지, 그리고 앞 절에서 variance 가 절반으로만 준 것이 $\rho\sigma^2$ 바닥값 때문인지다. 앞 예제의 $x = 0.95$ 한 곳에서 나무 하나의 분산과 나무 사이 상관을 재고, 평균하는 나무 수 $B$ 를 1 부터 200 까지 바꿨다 (측정 방법과 전체 수치는 [[#나무 사이 상관을 재는 방법과 나무 수별 수치|부록]]).

![[img-e1b1025ef6.png]]

빨간 곡선이 식, 파란 점이 측정값, 회색 점선이 나무가 서로 독립일 때의 $\sigma^2/B$, 회색 파선이 바닥값 $\rho\sigma^2$ 다. 이 위치에서 나무 하나의 분산은 $\sigma^2 = 0.109$, 나무 사이 상관은 $\rho = 0.43$ 이었다.

- **식이 측정값을 따라간다.** $B$ 가 1 부터 100 까지 식과 측정값의 차이가 0.003 이내다.
- **바닥값은 $\rho\sigma^2 = 0.43 \times 0.109 = 0.047$ 이다.** 나무를 10 개로 늘리면 분산이 0.106 에서 0.054 로 줄고, 50 개를 넘기면 0.047 에 붙어 더 줄지 않는다.
- **나무가 서로 독립이었다면 100 개에서 분산이 0.001 이었을 것이다.** 실제 0.047 은 그 40 배가 넘는다. bagging 뒤에 남은 variance 는 거의 전부 $\rho\sigma^2$ 다.

bagging 의 효과를 더 키우려면 $\rho$ 를 낮춰야 한다. 그것이 random forest 가 하는 일이다.

# E) Random forest 는 나무 사이의 상관을 낮춘다

[[random forest]] 는 bagging 한 decision tree 에 무작위성을 하나 더 넣는다. 나무는 노드(데이터를 어떤 feature 의 기준값으로 둘로 나누는 지점)를 위에서부터 차례로 만든다. random forest 는 노드를 하나 만들 때마다 전체 feature $p$ 개 중 $m$ 개만 무작위로 고르고, 그 $m$ 개 안에서만 가장 좋은 분할을 찾는다 ([Breiman, 2001](https://link.springer.com/article/10.1023/A:1010933404324)). $m = p$ 이면 모든 feature 를 다 보므로 그냥 나무를 bagging 한 것과 같다.

이렇게 하는 이유는 bagging 만으로는 나무끼리 닮기 때문이다. target 과 관계가 강한 feature 가 하나 있으면, 거의 모든 bootstrap 표본에서 그 feature 가 맨 위 분할로 뽑힌다. 그러면 나무들의 윗부분이 비슷해지고 $\rho$ 가 높아진다. $m$ 을 줄이면 그 feature 가 후보에 없는 노드가 생겨 나무마다 다른 feature 로 나누게 되고, $\rho$ 가 내려간다.

대가도 있다. 좋은 feature 가 후보에서 빠진 노드에서는 덜 좋은 분할을 고르므로 나무 하나가 나빠질 수 있다. 그러면 평균의 분산 식에서 $\sigma^2$ 가 커지고 bias 도 커질 수 있다.

이 실험은 $m$ 을 줄이는 것이 언제 이득이고 언제 손해인지 확인한다. feature 가 10 개인 두 데이터에서 $m$ 을 10, 3, 1 로 바꿨다. 두 데이터는 feature 끼리 서로를 대신할 수 있는지만 다르다 (데이터 정의와 전체 수치는 [[#Random forest 실험의 데이터와 전체 수치|부록]]).

- **데이터 1**: 10 개 중 5 개만 $y$ 와 관계가 있다. 나머지 5 개는 무관하다.
- **데이터 2**: 10 개 모두 같은 숨은 값에 서로 다른 잡음을 더한 사본이라, 어느 feature 로 나눠도 비슷하게 좋다.

| $m$ | 데이터 1 의 $\rho$ | 데이터 1 의 test RMSE | 데이터 2 의 $\rho$ | 데이터 2 의 test RMSE |
| --- | --- | --- | --- | --- |
| 10 (bagging) | 0.11 | 2.54 | 0.11 | 0.445 |
| 3 | 0.04 | 2.66 | 0.06 | 0.433 |
| 1 | 0.02 | 3.29 | 0.03 | 0.430 |

- 두 데이터 모두 $m$ 을 줄이면 $\rho$ 가 내려갔다. 결과를 가른 것은 나무 하나의 품질이다.
- **데이터 1** 에서 $m = 1$ 이면 노드의 절반이 무관한 feature 로 나뉜다. 나무 하나의 bias² 가 4.1 에서 9.2 로 커져, $\rho$ 가 낮아진 이득보다 컸다.
- **데이터 2** 에서는 $m$ 을 줄여도 나무 하나의 bias² 와 분산이 거의 그대로여서, $\rho$ 가 낮아진 만큼 test RMSE 가 나아졌다.
- 두 데이터 모두 100 개 평균의 bias² 가 나무 하나의 bias² 와 소수 셋째 자리까지 같았다. [[#학습 데이터가 바뀔 때 흔들리는 예측을 평균으로 줄인다|도입부의 설명]]대로 평균하는 단계는 bias 를 바꾸지 않는다. bias 를 바꾸는 것은 나무 하나를 어떻게 만드느냐($m$, bootstrap 표본)다.

$m$ 의 관례적 기본값은 분류에서 $\lfloor\sqrt{p}\rfloor$, 회귀에서 $\lfloor p/3 \rfloor$ 이다 (Hastie et al., 15.3 절). scikit-learn 1.1 부터 `RandomForestRegressor` 의 기본값은 `max_features=1.0`, 즉 모든 feature 를 보는 bagging 이고, `RandomForestClassifier` 는 `"sqrt"` 다. 데이터 1 처럼 $m$ 을 줄여 나빠지는 경우가 있으므로 $m$ 은 검증 오차나 [[#Out-of-bag 샘플로 검증 데이터 없이 test 오차를 추정한다|다음 절의 OOB 오차]]로 고른다.

# F) Out-of-bag 샘플로 검증 데이터 없이 test 오차를 추정한다

bootstrap 표본에서 빠질 확률을 계산한 대로, 각 학습 샘플은 bootstrap 표본의 약 37% 에서 빠진다. 어떤 샘플이 빠진 bootstrap 표본으로 학습한 나무에게 그 샘플은 처음 보는 데이터다. 이렇게 빠진 샘플을 그 나무의 **out-of-bag(OOB) 샘플** 이라고 한다. 학습 샘플마다 그 샘플을 보지 못한 나무들만으로 예측하면, 검증 데이터를 따로 떼지 않고도 test 오차를 추정할 수 있다.

$$
\hat y_i^{\,\text{OOB}} = \frac{1}{|S_i|}\sum_{b \in S_i} T_b(x_i), \qquad
\text{OOB RMSE} = \sqrt{\frac{1}{N}\sum_{i=1}^{N}\big(y_i - \hat y_i^{\,\text{OOB}}\big)^2}
$$

| 기호 | 뜻 |
| --- | --- |
| $S_i$ | 학습 샘플 $i$ 가 bootstrap 표본에 없었던 나무들의 번호 집합 |
| $\lvert S_i \rvert$ | 그 나무의 수. 나무가 $B$ 개면 평균 약 $0.37B$ 개 |
| $T_b(x_i)$ | $b$ 번째 나무가 $x_i$ 에서 내는 예측 |
| $N$ | 학습 샘플 수 |

데이터 전체를 학습에 쓰면서 test 오차를 추정할 수 있고, 추가 학습도 필요 없다.

이 추정이 실제 test 오차와 얼마나 맞는지 앞의 1 차원 예제에서 확인했다 ([[#OOB 실험|부록]]).

- **나무가 100 개면 맞는다.** OOB RMSE 0.370, 실제 test RMSE 0.369 다 (1,000 번 반복의 평균).
- **나무가 적으면 높게 나온다.** 나무 10 개에서 OOB RMSE 는 0.392 인데 실제 test RMSE 는 0.375 다. 각 샘플의 OOB 예측은 그 샘플이 빠진 평균 3.6 개 나무로만 만들어지므로, OOB 오차는 "나무 10 개의 앙상블" 이 아니라 "나무 약 4 개의 앙상블" 을 평가한다. 실제로 나무 4 개를 평균한 앙상블의 test RMSE 가 0.386 으로 OOB 값에 가깝다.

그래서 OOB 오차는 나무가 충분히 많을 때 test 오차의 추정값으로 쓴다. [[#예제의 나무들은 상관이 0.43 이라 variance 가 절반에서 멈춘다|나무 수에 따른 variance 그림]]에서 보았듯이 50 개를 넘으면 앙상블의 분산이 거의 바닥이므로, 약 $0.37B$ 개와 $B$ 개의 차이도 작아진다.

# G) Bagging 이 효과가 있는 모델과 거의 없는 모델

bagging 이 variance 만 줄인다면, variance 가 원래 작은 모델이나 오차의 대부분이 bias 인 모델에서는 효과가 거의 없어야 한다. 이 실험은 그 예측을 확인한다. 같은 1 차원 데이터에서 기본 모델만 바꿔 모델 100 개로 bagging 했다 ([[#기본 모델 비교와 boosting 설정|부록]]).

| 기본 모델 | 단독 test RMSE | bagging test RMSE | 단독 bias² | 단독 variance |
| --- | --- | --- | --- | --- |
| 깊은 decision tree | 0.427 | 0.368 | 0.0004 | 0.093 |
| 깊이 1 decision tree | 0.447 | 0.421 | 0.072 | 0.040 |
| 15-NN | 0.387 | 0.384 | 0.047 | 0.015 |
| 3 차 다항식 | 0.321 | 0.321 | 0.005 | 0.009 |
| 직선 (선형 회귀) | 0.546 | 0.547 | 0.200 | 0.013 |

깊이 1 decision tree 는 분할을 한 번만 해서 $x$ 축을 두 구간으로 나누고 구간마다 상수를 예측한다. 15-NN 은 새 입력에서 가장 가까운 학습 샘플 15 개의 $y$ 평균을 예측한다.

- **효과가 큰 모델**: 깊은 decision tree. bias 가 거의 0 이고 variance 가 가장 커서, bagging 이 줄일 몫이 가장 많다.
- **variance 는 줄지만 bias 가 남는 모델**: 깊이 1 decision tree. bagging 으로 variance 가 0.040 에서 0.019 로 절반이 됐지만, 사인 곡선을 계단 두 개로 표현하는 한계인 bias² 0.072 가 그대로 남아 test RMSE 가 0.421 에 머문다.
- **효과가 없는 모델**: 15-NN, 3 차 다항식, 직선. 학습 데이터가 바뀌어도 예측이 별로 변하지 않아 variance 가 0.009–0.015 로 작다. test RMSE 변화가 0.003 이하다.

[Breiman (1996)](https://link.springer.com/article/10.1007/BF00058655) 은 학습 데이터를 조금 바꿨을 때 예측이 크게 달라지는 모델을 **불안정한(unstable)** 모델이라고 부르고, bagging 은 불안정한 모델에서 효과가 크다고 정리했다. bagging 의 기본 모델로 가지치기하지 않은 깊은 나무를 쓰는 이유가 여기에 있다.

# H) Bagging 과 boosting 은 줄이는 오차가 다르다

[[boosting]] 도 모델 여러 개의 예측을 합치지만 모델을 만드는 방식이 다르다. bagging 은 모델들을 서로 독립으로 동시에 학습한다. boosting 은 모델을 하나씩 차례로 추가하고, 새 모델이 지금까지의 앙상블이 틀린 부분을 맞추도록 학습한다. 회귀에서 많이 쓰는 [[Gradient Boosting Machine|gradient boosting]] 에서 $k$ 번째 나무를 추가하는 한 단계는 다음과 같다.

$$
r_i = y_i - F_{k-1}(x_i), \qquad F_k(x) = F_{k-1}(x) + \eta\, h_k(x)
$$

| 기호 | 뜻 |
| --- | --- |
| $F_{k-1}(x)$ | 나무 $k-1$ 개까지 더한 현재 앙상블의 예측 |
| $r_i$ | 학습 샘플 $i$ 의 남은 오차. $k$ 번째 나무는 $(x_i, r_i)$ 를 학습 데이터로 삼는다 |
| $h_k(x)$ | $r_i$ 를 맞추도록 학습한 $k$ 번째 나무의 예측 |
| $\eta$ | learning rate. 새 나무의 예측을 얼마나 반영할지 정하는 0 과 1 사이의 비율 |

bagging 의 $\bar f$ 는 모든 모델에 같은 가중치 $1/B$ 를 주고 한 번에 평균하지만, boosting 의 $F_k$ 는 앞 단계의 결과 $F_{k-1}$ 에 의존하므로 차례로만 만들 수 있다.

이 차이가 어느 오차를 줄이는지로 이어지는지 보려고, [[#Bagging 이 효과가 있는 모델과 거의 없는 모델|앞 절]]에서 bias 가 남았던 깊이 1 decision tree 100 개를 두 방식으로 묶어 비교했다.

| 방법 (깊이 1 나무 100 개) | test RMSE | bias² | variance |
| --- | --- | --- | --- |
| 나무 하나 | 0.447 | 0.072 | 0.040 |
| bagging | 0.421 | 0.070 | 0.019 |
| gradient boosting | 0.349 | 0.009 | 0.023 |

bagging 은 bias² 를 거의 그대로 두었고, boosting 은 8 분의 1 로 줄였다. 계단 두 개짜리 나무를 차례로 더하면서 앞의 나무가 틀린 구간을 다음 나무가 고쳐, 합쳐진 예측이 여러 계단으로 사인 곡선을 따라가기 때문이다.

| 기준 | bagging | boosting |
| --- | --- | --- |
| 모델을 만드는 순서 | 서로 독립, 동시에 학습 가능 | 앞 모델의 결과를 보고 차례로 학습 |
| 각 모델이 학습하는 데이터 | 서로 다른 bootstrap 표본 | 전체 데이터, 앞 모델들이 남긴 오차 |
| 예측을 합치는 방법 | 단순 평균 또는 다수결 | learning rate 를 곱해 더함 |
| 주로 줄이는 오차 | variance | bias |
| 잘 맞는 기본 모델 | 깊은 나무처럼 bias 가 작고 variance 가 큰 모델 | 얕은 나무처럼 variance 가 작고 bias 가 큰 모델 |
| 모델 수를 늘리면 | test 오차가 바닥값으로 수렴하고 다시 오르지 않음 | 학습 데이터의 남은 오차를 계속 맞추므로, 너무 많으면 overfitting 할 수 있어 검증 오차로 개수를 정함 |

# I) 실무에서 정하는 값

- **나무 수**: 평균의 분산 식에서 나무 수가 줄이는 것은 $(1-\rho)\sigma^2/B$ 뿐이고, 이 항은 $B$ 가 커지면 0 으로 가기만 한다. 그래서 나무를 늘려도 test 오차가 다시 오르지 않는다. 앞 예제에서 test RMSE 는 나무 10 개에서 0.375, 50 개에서 0.369, 200 개에서 0.368 이었다. 나무 수는 overfitting 이 아니라 계산 비용과 test 오차가 더 줄지 않는 지점을 보고 정한다. scikit-learn 기본값은 `BaggingRegressor` 10 개, `RandomForestRegressor` 100 개다.
- **bootstrap 표본의 크기**: 표본을 $N$ 보다 작게 뽑으면(scikit-learn `max_samples`) 두 표본이 겹치는 샘플이 줄어 $\rho$ 가 내려가지만, 나무 하나가 보는 데이터도 줄어 $\sigma^2$ 가 커진다. 앞 예제에서는 표본을 절반으로 줄였을 때 $\rho$ 가 0.42 에서 0.22 로 내려가 test RMSE 가 0.368 에서 0.345 로 가장 낮았다 ([[#Bootstrap 표본 크기 실험|부록]]). 가장 좋은 크기는 데이터마다 다르므로 OOB 오차나 검증 오차로 고른다.
- **feature 수 $m$**: random forest 를 쓸 때. [[#Random forest 는 나무 사이의 상관을 낮춘다|random forest 절]]에서 본 대로 feature 가 서로를 대신할 수 있는지에 따라 최적값이 달라진다.

# J) 부록 실험 방법과 전체 수치

본문의 수치는 모두 Python 과 scikit-learn 1.2 로 직접 돌린 시뮬레이션 결과다.

## J.1) 1 차원 예제의 설정

본문의 1 차원 실험(깊은 나무 예제, 나무 사이 상관 측정, OOB, 기본 모델 비교, boosting 비교, 표본 크기)은 모두 같은 데이터 생성 방식을 쓴다.

1. 참 함수를 $y = \sin(2\pi x)$ 로 정하고, $x$ 를 0–1 구간에서 균등분포로 50 개 뽑는다. [[overfitting]] 노트의 다항식 예제는 같은 간격 10 개였지만, 나무는 $x$ 축을 구간으로 나눠 구간마다 상수 하나를 예측하므로 모양이 드러나도록 점을 늘렸다.
2. 각 $y$ 에 표준편차 0.3 인 정규분포 잡음을 더해 학습 데이터를 만든다.
3. 깊은 회귀 나무는 scikit-learn `DecisionTreeRegressor` 의 기본값(깊이 제한 없음, leaf 당 최소 샘플 1 개)이다.
4. test 오차는 같은 방식으로 만든 새 점 1,000 개로 잰다.
5. 1–4 를 학습 데이터를 새로 뽑아 가며 반복한다. 반복 횟수는 깊은 나무 예제·상관 측정·OOB 가 1,000 번, 기본 모델 비교·boosting 비교가 500 번, 표본 크기 실험이 300 번이다.

학습 RMSE 와 test RMSE 는 매 반복에서 하나씩 재고, 표에는 반복 전체의 평균을 적었다.

## J.2) bias 와 variance 를 재는 방법

1. 매 반복에서 0–1 구간에 같은 간격으로 놓은 $x$ 200 곳의 예측값을 기록한다.
2. 반복이 끝나면 각 $x$ 에서 예측값들의 평균과 분산을 구한다. 도입부 정의의 $\mathbb{E}_D$ 를 반복 횟수만큼의 평균으로 바꾼 것이다. (평균 − 참값)² 이 그 $x$ 의 $\operatorname{Bias}^2$, 분산이 그 $x$ 의 $\operatorname{Var}$ 이다.
3. 200 곳의 값을 평균해 표에 적는다.

## J.3) 나무 사이 상관을 재는 방법과 나무 수별 수치

1. 매 반복에서 bootstrap 나무 200 개를 학습하고, 나무마다 $x = 0.95$ 에서의 예측값을 기록한다. [[overfitting]] 노트에서 다항식 예측이 흔들리는 정도를 잰 것과 같은 위치이고, 참값은 $-0.31$ 이다.
2. 1,000 번 반복이 끝나면 예측값이 1,000 × 200 개 모인다. 이 전체의 분산이 $\sigma^2 = 0.109$ 다.
3. 같은 반복에서 나온 서로 다른 두 나무의 공분산을 모든 짝에 대해 평균하면 $\rho\sigma^2 = 0.0466$ 이다. 따라서 $\rho = 0.0466 / 0.109 = 0.43$ 이다.
4. 매 반복에서 앞쪽 나무 $B$ 개의 예측을 평균하고, 그 평균값 1,000 개의 분산을 잰다. 이것이 측정값이다.

| 나무 수 $B$ | 측정한 분산 | 식 $\rho\sigma^2 + (1-\rho)\sigma^2/B$ | 나무가 서로 독립일 때 $\sigma^2/B$ | test RMSE |
| --- | --- | --- | --- | --- |
| 1 | 0.106 | 0.109 | 0.109 | 0.434 |
| 2 | 0.080 | 0.078 | 0.054 | 0.403 |
| 5 | 0.060 | 0.059 | 0.022 | 0.382 |
| 10 | 0.054 | 0.053 | 0.011 | 0.375 |
| 20 | 0.052 | 0.050 | 0.005 | 0.372 |
| 50 | 0.048 | 0.048 | 0.002 | 0.369 |
| 100 | 0.047 | 0.047 | 0.001 | 0.369 |
| 200 | 0.047 | 0.047 | 0.001 | 0.368 |

$\sigma^2$ 와 $\rho\sigma^2$ 는 200 개 나무 전체에서 잰 값이라, $B = 200$ 에서는 식과 측정값이 정의상 같다. 확인할 것은 그 사이의 $B$ 다. test RMSE 열은 같은 나무들의 앞쪽 $B$ 개 평균을 새 점 1,000 개로 잰 값이다.

같은 위치에서 학습 데이터 50 개 전체로 만든 나무 하나의 분산은 0.099 로, bootstrap 나무 하나(0.106)보다 조금 작다. bootstrap 나무는 서로 다른 샘플을 약 32 개만 보기 때문이다. 그래서 bootstrap 나무 하나의 test RMSE(0.434)는 전체 데이터로 만든 나무(0.429)보다 조금 높고, 2 개를 평균하면(0.403) 그보다 낮아진다. bootstrap 절의 63.6% 도 이 실험의 bootstrap 표본 20 만 개에서 센 값이다.

## J.4) Random forest 실험의 데이터와 전체 수치

두 데이터 모두 학습 샘플 200 개, feature 10 개, 나무 100 개이고, 학습 데이터를 200 번 새로 뽑아 반복했다. $\rho$, $\sigma^2$, bias² 는 위의 1 차원 실험과 같은 방식으로 재되, test 점 500 곳에서 잰 값의 평균이다.

**데이터 1** 은 [Friedman (1991)](https://doi.org/10.1214/aos/1176347963) 의 벤치마크 함수다 (scikit-learn `make_friedman1`). $x_1, \dots, x_{10}$ 을 각각 0–1 균등분포로 뽑고 $y = 10\sin(\pi x_1 x_2) + 20(x_3 - 0.5)^2 + 10x_4 + 5x_5 + \varepsilon$ 로 만든다. $\varepsilon$ 은 표준편차 1 인 정규분포 잡음이고, $x_6$ 부터 $x_{10}$ 은 $y$ 와 관계가 없다.

| $m$ | $\rho$ | 나무 하나의 분산 $\sigma^2$ | bias² | 100 개 평균의 분산 | test RMSE |
| --- | --- | --- | --- | --- | --- |
| 10 (bagging) | 0.11 | 11.0 | 4.1 | 1.36 | 2.54 |
| 3 | 0.04 | 15.5 | 5.3 | 0.81 | 2.66 |
| 1 | 0.02 | 20.5 | 9.2 | 0.69 | 3.29 |

**데이터 2** 는 숨은 값 $z$ 를 0–1 균등분포로 뽑고, feature 10 개를 각각 $x_j = z + (\text{표준편차 0.2 인 잡음})$ 으로 만든다. $y = \sin(2\pi z) + (\text{표준편차 0.3 인 잡음})$ 이다.

| $m$ | $\rho$ | 나무 하나의 분산 $\sigma^2$ | bias² | 100 개 평균의 분산 | test RMSE |
| --- | --- | --- | --- | --- | --- |
| 10 (bagging) | 0.11 | 0.253 | 0.079 | 0.030 | 0.445 |
| 3 | 0.06 | 0.255 | 0.079 | 0.018 | 0.433 |
| 1 | 0.03 | 0.270 | 0.084 | 0.011 | 0.430 |

두 표 모두 bias² + 100 개 평균의 분산 + 잡음 분산(데이터 1 은 1, 데이터 2 는 0.09)의 제곱근이 test RMSE 와 맞는다. 예를 들어 데이터 1 의 $m = 1$ 은 $\sqrt{9.2 + 0.69 + 1} = 3.30$ 이다.

## J.5) OOB 실험

1 차원 예제에서 매 반복마다 OOB RMSE 와 실제 test RMSE 를 함께 재고 1,000 번 평균했다.

| 나무 수 | OOB RMSE | 같은 앙상블의 test RMSE |
| --- | --- | --- |
| 100 | 0.370 | 0.369 |
| 10 | 0.392 | 0.375 |

나무 100 개에서 한 번의 실험만 보면 OOB RMSE 와 test RMSE 의 차이는 평균 0.036 이었다. 나무 10 개일 때는 샘플의 1.1% 가 10 개 표본에 모두 들어가 OOB 예측을 만들 수 없어 계산에서 뺐다.

## J.6) 기본 모델 비교와 boosting 설정

1 차원 예제에서 기본 모델만 바꿔 500 번 반복했다. bagging 은 모두 bootstrap 표본 100 개로 모델 100 개를 평균했다. gradient boosting 은 scikit-learn `GradientBoostingRegressor` 로 깊이 1 나무 100 개, learning rate 0.1 이다.

| 기본 모델 | 단독 test RMSE | bagging test RMSE | 단독 bias² | 단독 variance | bagging variance |
| --- | --- | --- | --- | --- | --- |
| 깊은 decision tree | 0.427 | 0.368 | 0.0004 | 0.093 | 0.045 |
| 깊이 1 decision tree | 0.447 | 0.421 | 0.072 | 0.040 | 0.019 |
| 15-NN | 0.387 | 0.384 | 0.047 | 0.015 | 0.013 |
| 3 차 다항식 | 0.321 | 0.321 | 0.005 | 0.009 | 0.009 |
| 직선 (선형 회귀) | 0.546 | 0.547 | 0.200 | 0.013 | 0.013 |

3 차 다항식과 직선은 bagging 후 test RMSE 가 0.001 미만으로 조금 나빠졌다. bootstrap 표본마다 서로 다른 샘플을 약 32 개만 보므로 모델 하나가 원래보다 조금 덜 정확하고, 그 몫을 평균이 되돌리지 못한 것으로 보인다.

## J.7) Bootstrap 표본 크기 실험

1 차원 예제에서 bootstrap 표본의 크기만 바꿨다 (복원추출, 나무 100 개, 300 번 반복). $\rho$, $\sigma^2$, 평균의 분산은 $x = 0.95$ 에서 잰 값이다.

| 표본 크기 | $\rho$ | 나무 하나의 분산 $\sigma^2$ | 100 개 평균의 분산 | test RMSE |
| --- | --- | --- | --- | --- |
| $N$ (50 개) | 0.42 | 0.108 | 0.046 | 0.368 |
| $0.5N$ (25 개) | 0.22 | 0.129 | 0.029 | 0.345 |
| $0.2N$ (10 개) | 0.12 | 0.177 | 0.022 | 0.347 |

10 개까지 줄이면 평균의 분산은 더 작아지지만 test RMSE 는 0.347 로 절반일 때보다 조금 높다. 점 10 개로 학습한 나무는 계단이 몇 개뿐이라 사인 곡선을 거칠게 근사하고, 그 몫이 분산 감소를 상쇄한 것으로 보인다.
