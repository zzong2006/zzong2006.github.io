# A) 여러 표본으로 학습한 모델의 예측을 평균한다

Bagging(bootstrap aggregating)은 학습 데이터에서 무작위로 다시 뽑은 표본을 여러 개 만들고, 표본마다 모델을 따로 학습한 뒤 그 예측을 평균하는 방법이다. [Breiman (1996)](https://link.springer.com/article/10.1007/BF00058655) 이 제안했고, [[random forest]] 의 바탕이 된다. 여러 모델의 예측을 합쳐 하나의 예측을 만드는 방법을 통틀어 [[ensemble]] 이라고 하는데, bagging 은 그중 가장 단순한 형태다.

## A.1) 학습 데이터가 바뀔 때 흔들리는 예측을 평균으로 줄인다

[[Decision Tree]] 같은 모델은 학습 데이터를 조금만 바꿔도 예측이 크게 달라진다. 나무의 첫 분할 위치가 바뀌면 그 아래 구조가 통째로 바뀌기 때문이다.

이 흔들림을 재는 방법은 다음과 같다. 같은 분포에서 학습 데이터를 여러 번 새로 뽑아, 뽑을 때마다 모델을 다시 학습한다. 그리고 한 입력 $x$ 에서의 예측값을 모은다.

- 모은 예측값들이 자기 평균 주위로 흩어진 정도(분산)를 **variance** 라고 한다.
- 모은 예측값들의 평균이 참값에서 벗어난 정도를 **bias** 라고 한다.

새 데이터에서의 기대 제곱 오차는 bias 의 제곱, variance, 데이터 자체에 섞인 잡음의 분산을 더한 값이다 ([[Bias-variance tradeoff]]). 학습 데이터의 잡음까지 따라가서 variance 가 커진 상태가 [[overfitting]] 이다.

학습 데이터를 $B$ 번 따로 뽑을 수 있다고 해 보자. 서로 독립인 학습 데이터로 모델 $B$ 개를 만들고 예측을 평균하면 다음 두 가지가 성립한다.

- 평균의 기댓값(무한히 반복했을 때의 평균)은 모델 하나의 기댓값과 같다. 그래서 bias 는 그대로다.
- 서로 독립인 값 $B$ 개를 평균한 값의 분산은 값 하나의 분산의 $1/B$ 이다. 그래서 variance 가 $1/B$ 로 준다.

실제로는 학습 데이터가 하나뿐이다. bagging 은 그 하나에서 표본을 다시 뽑아 "따로 뽑은 학습 데이터" 를 흉내 낸다. 다시 뽑은 표본들은 모두 같은 학습 데이터에서 나오므로 서로 독립이 아니다. 그래서 실제로 줄어드는 폭은 $1/B$ 보다 작다. 얼마나 작은지는 뒤의 "평균하는 모델끼리 상관이 있으면 variance 가 바닥에서 멈춘다" 절에서 계산한다.

## A.2) 절차

학습 데이터에 샘플이 $N$ 개 있을 때 다음과 같이 한다.

1. 학습 데이터에서 샘플 하나를 무작위로 뽑아 기록하고 다시 돌려놓는다. 이것을 $N$ 번 반복해 크기 $N$ 인 표본을 만든다. 이 표본을 **bootstrap 표본** 이라고 한다 ([[bootstrapping]]).
2. 1 을 $B$ 번 반복해 bootstrap 표본 $B$ 개를 만든다.
3. 각 bootstrap 표본으로 같은 종류의 모델을 하나씩 따로 학습한다. 모델끼리 서로의 결과를 쓰지 않으므로 동시에 학습할 수 있다.
4. 새 입력이 들어오면 $B$ 개 모델이 각자 예측한다.
	- 회귀: $B$ 개 예측값의 평균을 최종 예측으로 쓴다.
	- 분류: 가장 많은 모델이 고른 클래스를 쓰거나(다수결), 각 모델이 낸 클래스별 확률을 평균해 가장 높은 클래스를 쓴다.

# B) Bootstrap 표본에는 원래 샘플의 약 63% 가 들어간다

bootstrap 표본을 만들 때처럼 뽑은 것을 돌려놓고 다시 뽑는 방식을 **복원추출** 이라고 한다. 복원추출에서는 같은 샘플이 여러 번 뽑힐 수 있고, 한 번도 뽑히지 않는 샘플도 생긴다. 예를 들어 샘플 1–5 에서 다섯 번 뽑아 2, 5, 2, 1, 2 가 나왔다면, 2 번은 세 번 들어가고 3 번과 4 번은 빠진다.

특정 샘플 하나가 bootstrap 표본에서 빠질 확률은 다음과 같이 계산한다.

1. 한 번 뽑을 때 그 샘플이 뽑히지 않을 확률은 $1 - 1/N$ 이다.
2. $N$ 번의 뽑기는 서로 독립이므로, $N$ 번 내내 뽑히지 않을 확률은 이 값을 $N$ 번 곱한 것이다.

$$
P(\text{샘플 } i \text{ 가 빠짐}) = \left(1 - \frac{1}{N}\right)^N \;\longrightarrow\; e^{-1} \approx 0.368 \quad (N \to \infty)
$$

| 기호 | 뜻 |
| --- | --- |
| $N$ | 원래 학습 데이터의 샘플 수이자, bootstrap 표본의 크기 |
| $i$ | 원래 학습 데이터에서 특정 샘플 하나의 번호 |
| $e$ | 자연상수 2.718… |

| $N$ | 빠질 확률 | 표본에 한 번 이상 들어갈 확률 |
| --- | --- | --- |
| 5 | $0.8^5 = 0.328$ | 67.2% |
| 50 | $0.98^{50} = 0.364$ | 63.6% |
| 무한대 | $e^{-1} = 0.368$ | 63.2% |

뒤의 예제에서 $N = 50$ 으로 bootstrap 표본을 20 만 번 만들어 서로 다른 샘플의 비율을 세어 보면 평균 63.6% 였다. 계산과 같다.

여러 번 뽑힌 샘플은 그 횟수만큼 학습에 반영된다. 회귀 나무가 구간의 평균을 낼 때나 최소제곱법이 오차 제곱을 더할 때, 세 번 뽑힌 샘플은 세 번 더해진다. 그래서 bootstrap 표본은 원래 샘플에 0, 1, 2, … 의 무작위 가중치를 붙인 것과 같다. 표본마다 이 가중치가 다르므로 표본마다 다른 모델이 나온다.

표본에서 빠진 약 37% 의 샘플은 그 모델이 학습 때 보지 못한 데이터다. 이 샘플들로 별도 검증 데이터 없이 test 오차를 추정할 수 있다. 뒤의 "Out-of-bag 샘플로 검증 데이터 없이 test 오차를 추정한다" 절에서 다룬다.

# C) 예제: 깊은 decision tree 100 개를 평균하기

## C.1) 실험 설정

[[overfitting]] 노트의 다항식 예제와 같은 참 함수와 잡음을 쓰되, 모델을 decision tree 로 바꿨다. 나무는 $x$ 축을 구간으로 나눠 구간마다 상수 하나를 예측하므로, 모양이 드러나려면 점이 10 개보다 많아야 해서 50 개로 늘렸다. 아래 수치는 모두 직접 돌린 시뮬레이션 결과다 (Python, scikit-learn 1.2).

1. 참 함수를 $y = \sin(2\pi x)$ 로 정하고, $x$ 를 0–1 구간에서 균등분포로 50 개 뽑는다.
2. 각 $y$ 에 표준편차 0.3 인 정규분포 잡음을 더해 학습 데이터를 만든다.
3. **나무 하나**: 학습 데이터 50 개 전체로 깊은 회귀 나무 하나를 학습한다.
4. **bagging**: bootstrap 표본 100 개를 만들고, 표본마다 깊은 회귀 나무를 하나씩 학습해 예측을 평균한다.
5. 같은 방식으로 만든 새 점 1,000 개로 test 오차를 잰다.

회귀 나무는 $x$ 축을 여러 구간으로 나누고, 각 구간의 예측값을 그 구간에 들어온 학습 샘플 $y$ 의 평균으로 둔다. 이 구간 하나를 **leaf** 라고 한다. 여기서 "깊은" 나무는 깊이 제한 없이 leaf 마다 $x$ 값이 하나만 남을 때까지 나눈 나무다 (scikit-learn `DecisionTreeRegressor` 의 기본값). 이 나무는 각 학습 샘플의 $y$ 를 그대로 예측하므로 학습 오차가 0 이다. 9 차 다항식이 점 10 개를 모두 지난 것과 같은 상태다.

초록 곡선이 참 함수, 파란 원이 학습 데이터, 빨간 선이 예측이다.

## C.3) 학습 데이터를 바꿔 가며 잰 bias 와 variance

아래 두 그림은 학습 데이터를 20 번 새로 뽑아, 뽑을 때마다 만든 예측 20 개를 겹쳐 그린 것이다. 나무 하나(왼쪽 아래)는 학습 데이터가 바뀔 때마다 예측이 크게 달라져 띠가 넓다. bagging(오른쪽 아래)은 띠가 좁다.

이를 수치로 보기 위해 학습 데이터를 1,000 번 새로 뽑아 같은 실험을 반복했다.

| 모델 | 학습 RMSE | test RMSE |
| --- | --- | --- |
| 깊은 나무 하나 | 0.000 | 0.429 |
| bagging (나무 100 개) | 0.136 | 0.369 |

RMSE 는 오차 제곱의 평균에 제곱근을 씌운 값으로 $y$ 와 같은 단위다. 매 반복에서 학습 RMSE 와 test RMSE 를 하나씩 재고, 표에는 1,000 번의 평균을 적었다. 잡음의 표준편차가 0.3 이므로 test RMSE 는 0.3 아래로 내려갈 수 없다.

bagging 의 학습 RMSE 가 0 이 아닌 이유는 각 학습 샘플이 나무 100 개 중 약 37 개의 bootstrap 표본에서 빠지기 때문이다. 그 37 개 나무는 그 샘플을 보지 못했으므로 주변 샘플로 예측하고, 그 값이 평균에 섞인다.

test 오차가 줄어든 원인을 나누기 위해 bias 와 variance 를 따로 쟀다.

1. 매 반복에서 0–1 구간에 같은 간격으로 놓은 $x$ 200 곳의 예측값을 기록한다.
2. 1,000 번이 끝나면 각 $x$ 에서 예측값 1,000 개의 평균과 분산을 구한다. (평균 − 참값)² 이 그 $x$ 의 bias 제곱, 분산이 그 $x$ 의 variance 다.
3. 200 곳의 값을 평균해 표에 적는다.

| 모델 | bias² | variance | 잡음 분산 | 합 | 합의 제곱근 |
| --- | --- | --- | --- | --- | --- |
| 깊은 나무 하나 | 0.0003 | 0.095 | 0.09 | 0.185 | 0.430 |
| bagging (나무 100 개) | 0.0009 | 0.046 | 0.09 | 0.137 | 0.369 |

마지막 열이 앞 표의 test RMSE 와 반올림 차이 0.001 안에서 맞는다. test 오차 제곱이 bias², variance, 잡음 분산으로 나뉜다는 식이 이 예제에서 그대로 성립한다.

- 깊은 나무의 bias² 는 0.0003 으로 거의 0 이다. 학습 데이터를 바꿔 가며 평균하면 예측이 참 곡선과 거의 겹친다는 뜻이다. 깊은 나무의 오차는 대부분 variance 에서 온다.
- bagging 은 variance 를 0.095 에서 0.046 으로 절반가량 줄였다. test RMSE 가 줄어든 것은 거의 전부 이 몫이다.
- bias² 는 0.0003 에서 0.0009 로 조금 늘었다. 평균의 기댓값은 평균하는 나무 하나의 기댓값과 같은데, 그 나무는 전체 50 개가 아니라 서로 다른 샘플 약 32 개로 학습한 bootstrap 나무이기 때문이다. 다만 절대량이 variance 의 감소폭보다 훨씬 작다.

나무 100 개를 평균했는데 variance 는 $1/100$ 이 아니라 절반 정도로만 줄었다. 다음 절에서 그 이유를 계산한다.

# D) 평균하는 모델끼리 상관이 있으면 variance 가 바닥에서 멈춘다

## D.1) 상관된 값 B 개를 평균한 분산

입력 $x$ 하나를 고정하고, $b$ 번째 나무의 그 위치 예측을 $T_b$ 라고 하자. $T_b$ 는 무작위 값이다. 학습 데이터를 무엇으로 뽑았는지, 그 학습 데이터에서 bootstrap 표본을 무엇으로 뽑았는지에 따라 달라지기 때문이다.

| 기호 | 뜻 |
| --- | --- |
| $T_b$ | $b$ 번째 bootstrap 나무가 고정된 입력 $x$ 에서 내는 예측값 |
| $B$ | 평균하는 나무의 수 |
| $\sigma^2$ | 나무 하나의 예측값 $T_b$ 의 분산. 학습 데이터 뽑기와 bootstrap 뽑기 양쪽의 무작위성을 다 포함한다 |
| $\operatorname{Cov}(T_b, T_{b'})$ | 두 나무 예측의 공분산. 두 값이 각자의 평균보다 함께 크거나 함께 작은 경향이 강할수록 큰 양수가 된다 |
| $\rho$ | 같은 학습 데이터에서 만든 서로 다른 두 나무 $T_b$, $T_{b'}$ 의 상관계수. 공분산을 두 표준편차의 곱(여기서는 $\sigma^2$)으로 나눈 값으로, 0 이면 서로 무관하고 1 이면 늘 같은 값을 낸다 |

모든 나무가 같은 방식으로 만들어지므로 $\sigma^2$ 와 $\rho$ 는 나무마다 같다. 평균의 분산은 다음 순서로 계산한다.

1. 합의 분산은 각 항의 분산을 모두 더하고, 서로 다른 두 항의 공분산을 모든 짝에 대해 더한 것이다.
2. 분산 항은 $B$ 개이고 각각 $\sigma^2$ 다.
3. 서로 다른 두 나무의 짝은 순서를 따져 $B(B-1)$ 개이고, 각 공분산은 상관계수의 정의에 따라 $\rho\sigma^2$ 다.
4. 평균은 합을 $B$ 로 나눈 것이므로 분산은 $1/B^2$ 배가 된다.

$$
\begin{aligned}
\operatorname{Var}\left(\frac{1}{B}\sum_{b=1}^{B} T_b\right)
&= \frac{1}{B^2}\left[\sum_{b} \operatorname{Var}(T_b) + \sum_{b \neq b'} \operatorname{Cov}(T_b, T_{b'})\right] \\
&= \frac{1}{B^2}\left[B\sigma^2 + B(B-1)\rho\sigma^2\right] \\
&= \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2
\end{aligned}
$$

[Hastie, Tibshirani, Friedman (2009)](https://hastie.su.domains/ElemStatLearn/) 의 식 15.1 과 같다. 두 항의 뜻은 다음과 같다.

- **둘째 항** $(1-\rho)\sigma^2/B$ 는 나무를 늘리면 0 으로 간다. 같은 학습 데이터 안에서 bootstrap 표본이 달라서 생기는 흔들림이다.
- **첫째 항** $\rho\sigma^2$ 는 $B$ 와 상관없이 남는다. 모든 나무가 같은 학습 데이터에서 나왔기 때문에 함께 흔들리는 몫이다. 학습 데이터가 우연히 어떤 잡음을 담고 있으면, 그 잡음은 거의 모든 bootstrap 표본에 들어가고 모든 나무가 같은 방향으로 따라간다.

$\rho = 0$ 이면 앞의 "학습 데이터를 B 번 따로 뽑는" 이상적인 경우가 되어 분산이 $\sigma^2/B$ 다. $\rho = 1$ 이면 평균해도 분산이 $\sigma^2$ 그대로다.

## D.2) 예제에서 잰 상관과 나무 수에 따른 variance

앞 예제에서 $x = 0.95$ 한 곳을 골라 이 식을 확인했다. [[overfitting]] 노트에서 다항식 예측이 흔들리는 정도를 잰 것과 같은 위치이고, 참값은 $-0.31$ 이다.

1. 매 반복에서 bootstrap 나무 200 개를 학습하고, 나무마다 $x = 0.95$ 에서의 예측값을 기록한다.
2. 1,000 번 반복이 끝나면 예측값이 1,000 × 200 개 모인다. 이 전체의 분산이 $\sigma^2$ 이고, 0.109 였다.
3. 같은 반복에서 나온 서로 다른 두 나무의 공분산을 모든 짝에 대해 평균하면 $\rho\sigma^2$ 이고, 0.0466 이었다. 따라서 $\rho = 0.0466 / 0.109 = 0.43$ 이다.
4. 매 반복에서 앞쪽 나무 $B$ 개의 예측을 평균하고, 그 평균값 1,000 개의 분산을 잰다. 이것이 측정값이다.

| 나무 수 $B$ | 측정한 분산 | 식 $\rho\sigma^2 + (1-\rho)\sigma^2/B$ | 나무가 서로 독립일 때 $\sigma^2/B$ |
| --- | --- | --- | --- |
| 1 | 0.106 | 0.109 | 0.109 |
| 2 | 0.080 | 0.078 | 0.054 |
| 5 | 0.060 | 0.059 | 0.022 |
| 10 | 0.054 | 0.053 | 0.011 |
| 20 | 0.052 | 0.050 | 0.005 |
| 50 | 0.048 | 0.048 | 0.002 |
| 100 | 0.047 | 0.047 | 0.001 |
| 200 | 0.047 | 0.047 | 0.001 |

$\sigma^2$ 와 $\rho\sigma^2$ 는 200 개 나무 전체에서 잰 값이라, $B = 200$ 에서는 식과 측정값이 정의상 같다. 확인할 것은 그 사이의 $B$ 에서도 식이 측정값을 따라가는지다. 1 부터 100 까지 차이가 0.003 이내다.

![[img-e1b1025ef6.png]]

빨간 곡선이 식, 파란 점이 측정값, 회색 점선이 나무가 서로 독립일 때의 $\sigma^2/B$ 다. 회색 파선이 바닥값 $\rho\sigma^2 = 0.047$ 이다.

- 나무를 1 개에서 10 개로 늘리면 분산이 0.106 에서 0.054 로 줄어든다. 줄일 수 있는 몫 $(1-\rho)\sigma^2 = 0.062$ 의 대부분이 이 구간에서 사라진다.
- 50 개를 넘기면 분산이 바닥값 0.047 에 거의 붙어 더 줄지 않는다.
- 나무가 서로 독립이었다면 100 개에서 분산이 0.001 이었을 것이다. 실제 0.047 은 그 40 배가 넘는다. bagging 뒤에 남은 variance 는 거의 전부 $\rho\sigma^2$ 다.

같은 위치에서 학습 데이터 50 개 전체로 만든 나무 하나의 분산은 0.099 였다. bootstrap 나무 하나의 분산(표의 $B = 1$, 0.106)은 이보다 조금 크다. bootstrap 나무는 서로 다른 샘플을 약 32 개만 보기 때문이다. 그래서 bootstrap 나무를 하나만 쓰면 전체 데이터로 만든 나무보다 test RMSE 가 조금 높다 (0.434 대 0.429). 2 개를 평균하면 0.403 으로 내려가 전체 데이터로 만든 나무보다 낮아진다.

bagging 의 효과를 키우려면 $\rho$ 를 낮춰야 한다. 그것이 random forest 가 하는 일이다.

# E) Random forest 는 나무 사이의 상관을 낮춘다

## E.1) 분할마다 쓸 feature 를 무작위로 고른다

[[random forest]] 는 bagging 한 decision tree 에 무작위성을 하나 더 넣는다. 나무는 노드(데이터를 어떤 feature 의 기준값으로 둘로 나누는 지점)를 위에서부터 차례로 만든다. random forest 는 노드를 하나 만들 때마다 전체 feature $p$ 개 중 $m$ 개만 무작위로 고르고, 그 $m$ 개 안에서만 가장 좋은 분할을 찾는다 ([Breiman, 2001](https://link.springer.com/article/10.1023/A:1010933404324)). $m = p$ 이면 모든 feature 를 다 보므로 그냥 나무를 bagging 한 것과 같다.

이렇게 하는 이유는 bagging 만으로는 나무끼리 닮기 때문이다. target 과 관계가 강한 feature 가 하나 있으면, 거의 모든 bootstrap 표본에서 그 feature 가 맨 위 분할로 뽑힌다. 그러면 나무들의 윗부분이 비슷해지고 $\rho$ 가 높아진다. $m$ 을 줄이면 그 feature 가 후보에 없는 노드가 생겨 나무마다 다른 feature 로 나누게 되고, $\rho$ 가 내려간다.

대신 대가가 있다. 좋은 feature 가 후보에서 빠진 노드에서는 덜 좋은 분할을 고르므로, 나무 하나의 품질이 떨어질 수 있다. 그러면 평균의 분산 식에서 나무 하나의 분산 $\sigma^2$ 가 커지고 bias 도 커질 수 있다. 그래서 $m$ 을 줄였을 때 결과가 좋아지는지는 데이터에 달려 있다.

## E.2) 두 데이터에서 m 을 바꿔 본 결과

feature 가 10 개인 데이터 두 종류에서 $m$ 을 10, 3, 1 로 바꿔 직접 실험했다. 두 데이터 모두 학습 샘플 200 개, 나무 100 개이고, 학습 데이터를 200 번 새로 뽑아 반복했다. $\rho$, $\sigma^2$, bias² 는 앞의 1 차원 예제와 같은 방식으로 재되, 한 위치가 아니라 test 점 500 곳에서 잰 값의 평균이다.

**데이터 1 — 10 개 중 5 개만 쓸모 있는 feature.** [Friedman (1991)](https://doi.org/10.1214/aos/1176347963) 의 벤치마크 함수를 썼다 (scikit-learn `make_friedman1`). $x_1, \dots, x_{10}$ 을 각각 0–1 균등분포로 뽑고 $y = 10\sin(\pi x_1 x_2) + 20(x_3 - 0.5)^2 + 10x_4 + 5x_5 + \varepsilon$ 로 만든다. $\varepsilon$ 은 표준편차 1 인 정규분포 잡음이다. $x_6$ 부터 $x_{10}$ 은 $y$ 와 관계가 없다.

| $m$ | 나무 사이 상관 $\rho$ | 나무 하나의 분산 $\sigma^2$ | bias² | 100 개 평균의 분산 | test RMSE |
| --- | --- | --- | --- | --- | --- |
| 10 (bagging) | 0.11 | 11.0 | 4.1 | 1.36 | 2.54 |
| 3 | 0.04 | 15.5 | 5.3 | 0.81 | 2.66 |
| 1 | 0.02 | 20.5 | 9.2 | 0.69 | 3.29 |

**데이터 2 — 같은 정보를 담은 feature 10 개.** 숨은 값 $z$ 를 0–1 균등분포로 뽑고, feature 10 개를 각각 $x_j = z + (\text{표준편차 0.2 인 잡음})$ 으로 만든다. $y = \sin(2\pi z) + (\text{표준편차 0.3 인 잡음})$ 이다. 모든 feature 가 $z$ 를 비슷한 정확도로 담고 있으며, 잡음만 서로 다르다.

| $m$ | 나무 사이 상관 $\rho$ | 나무 하나의 분산 $\sigma^2$ | bias² | 100 개 평균의 분산 | test RMSE |
| --- | --- | --- | --- | --- | --- |
| 10 (bagging) | 0.11 | 0.253 | 0.079 | 0.030 | 0.445 |
| 3 | 0.06 | 0.255 | 0.079 | 0.018 | 0.433 |
| 1 | 0.03 | 0.270 | 0.084 | 0.011 | 0.430 |

두 데이터 모두 $m$ 을 줄이면 $\rho$ 가 내려가고 100 개 평균의 분산이 줄었다. 결과가 갈린 것은 나무 하나의 품질이다.

- **데이터 1** 에서는 feature 절반이 쓸모없다. $m = 1$ 이면 노드의 절반에서 무관한 feature 로 나누게 되어, bias² 가 4.1 에서 9.2 로 커졌다. 평균의 분산이 0.67 줄어든 것보다 bias² 가 5.1 늘어난 것이 커서 test RMSE 가 2.54 에서 3.29 로 나빠졌다.
- **데이터 2** 에서는 어느 feature 로 나눠도 비슷하게 좋다. $m$ 을 줄여도 $\sigma^2$ 와 bias² 가 거의 그대로이고, 줄어든 $\rho$ 만큼 test RMSE 가 0.445 에서 0.430 으로 나아졌다.

표의 bias² 는 나무 하나의 값이다. 같은 실험에서 100 개 평균의 bias² 도 쟀는데, 여섯 경우 모두 나무 하나의 값과 소수 셋째 자리까지 같았다. 평균의 기댓값은 나무 하나의 기댓값과 같다는 도입부의 설명을 실제 값으로 확인한 것이다. 평균하는 단계는 bias 를 바꾸지 않는다. bias 를 바꾸는 것은 나무 하나를 어떻게 만드느냐(bootstrap 표본, $m$)다.

$m$ 의 관례적 기본값은 분류에서 $\lfloor\sqrt{p}\rfloor$, 회귀에서 $\lfloor p/3 \rfloor$ 이다 (Hastie et al., 15.3 절). scikit-learn 1.1 부터 `RandomForestRegressor` 의 기본값은 `max_features=1.0`, 즉 모든 feature 를 보는 bagging 이고, `RandomForestClassifier` 는 `"sqrt"` 다. 데이터 1 처럼 $m$ 을 줄여 나빠지는 경우가 있으므로 $m$ 은 검증 오차나 다음 절의 OOB 오차로 고른다.

# F) Out-of-bag 샘플로 검증 데이터 없이 test 오차를 추정한다

앞에서 계산했듯이 각 학습 샘플은 bootstrap 표본의 약 37% 에서 빠진다. 어떤 샘플이 빠진 bootstrap 표본으로 학습한 나무에게 그 샘플은 처음 보는 데이터다. 이렇게 빠진 샘플을 그 나무의 **out-of-bag(OOB) 샘플** 이라고 한다. OOB 오차는 다음과 같이 구한다.

1. 학습 샘플 $i$ 마다, $i$ 가 bootstrap 표본에 없었던 나무들만 모은다. 나무가 100 개면 평균 약 37 개다.
2. 모은 나무들의 $x_i$ 에서의 예측을 평균해 $i$ 의 OOB 예측으로 삼는다.
3. 모든 학습 샘플에서 OOB 예측과 실제 $y_i$ 의 RMSE 를 구한다. 이것이 OOB RMSE 다.

학습 데이터를 따로 떼어 검증 데이터를 만들지 않아도 되므로, 데이터 전체를 학습에 쓰면서 test 오차를 추정할 수 있다. 추가 학습도 필요 없다.

앞의 1 차원 예제에서 매 반복마다 OOB RMSE 와 실제 test RMSE 를 함께 재고 1,000 번 평균했다.

| 나무 수 | OOB RMSE | 같은 앙상블의 test RMSE |
| --- | --- | --- |
| 100 | 0.370 | 0.369 |
| 10 | 0.392 | 0.375 |

- 나무가 100 개면 OOB RMSE 의 평균이 test RMSE 의 평균과 거의 같다. 한 번의 실험만 보면 두 값의 차이는 평균 0.036 이었다.
- 나무가 10 개면 OOB RMSE 가 test RMSE 보다 높게 나온다. 각 샘플의 OOB 예측은 10 개 중 그 샘플이 빠진 평균 3.6 개 나무로만 만들어지기 때문이다. 실제로 나무 4 개를 평균한 앙상블의 test RMSE 가 0.386 으로 OOB RMSE 0.392 와 가깝다. OOB 오차는 "나무 $B$ 개의 앙상블" 이 아니라 "나무 약 $0.37B$ 개의 앙상블" 을 평가한다. 나무 10 개일 때는 샘플의 1.1% 가 10 개 표본에 모두 들어가 OOB 예측을 만들 수 없어 계산에서 뺐다.

나무 수에 따른 variance 표에서 보았듯이 나무 수가 50 개를 넘으면 앙상블의 분산이 거의 바닥이므로, $0.37B$ 개와 $B$ 개의 차이도 작아진다. OOB 오차는 나무가 충분히 많을 때 test 오차의 추정값으로 쓴다.

# G) Bagging 이 효과가 있는 모델과 거의 없는 모델

bagging 은 variance 만 줄이고 bias 는 그대로 둔다. 그러면 variance 가 원래 작은 모델이나, 오차의 대부분이 bias 인 모델에서는 줄일 것이 거의 없다. 같은 1 차원 데이터(학습 샘플 50 개)에서 모델만 바꿔 나무 100 개 대신 모델 100 개로 bagging 했다. 학습 데이터를 500 번 새로 뽑아 반복했고, bias² 와 variance 는 깊은 나무 예제와 같은 방식(같은 간격의 $x$ 200 곳에서 재서 평균)으로 쟀다.

| 기본 모델 | 단독 test RMSE | bagging test RMSE | 단독 bias² | 단독 variance | bagging variance |
| --- | --- | --- | --- | --- | --- |
| 깊은 decision tree | 0.427 | 0.368 | 0.0004 | 0.093 | 0.045 |
| 깊이 1 decision tree | 0.447 | 0.421 | 0.072 | 0.040 | 0.019 |
| 15-NN | 0.387 | 0.384 | 0.047 | 0.015 | 0.013 |
| 3 차 다항식 | 0.321 | 0.321 | 0.005 | 0.009 | 0.009 |
| 직선 (선형 회귀) | 0.546 | 0.547 | 0.200 | 0.013 | 0.013 |

깊이 1 decision tree 는 분할을 한 번만 해서 $x$ 축을 두 구간으로 나누고 구간마다 상수를 예측한다. 15-NN 은 새 입력에서 가장 가까운 학습 샘플 15 개의 $y$ 평균을 예측한다.

- **깊은 decision tree** 는 bias 가 거의 0 이고 variance 가 가장 크다. bagging 으로 variance 가 절반이 되어 test RMSE 가 가장 많이 줄었다.
- **깊이 1 decision tree** 도 variance 는 절반이 됐다 (0.040 → 0.019). 하지만 오차의 큰 몫인 bias² 0.072 가 그대로 남아 test RMSE 는 0.421 에 머문다. 사인 곡선을 계단 두 개로 표현하는 한계는 평균해도 사라지지 않는다.
- **15-NN, 3 차 다항식, 직선** 은 학습 데이터가 바뀌어도 예측이 별로 변하지 않는다. variance 가 0.009–0.015 로 작아서 줄일 몫이 없다. test RMSE 의 변화는 0.003 이하이고, 3 차 다항식과 직선은 오히려 0.001 미만으로 조금 나빠졌다. 3 차 다항식과 직선은 bootstrap 표본마다 서로 다른 샘플을 약 32 개만 보므로 모델 하나가 원래보다 조금 덜 정확하고, 그 몫을 평균이 되돌리지 못한 것으로 보인다.

Breiman (1996) 은 학습 데이터를 조금 바꿨을 때 예측이 크게 달라지는 모델을 **불안정한(unstable)** 모델이라고 부르고, bagging 은 불안정한 모델에서 효과가 크고 안정적인 모델에서는 거의 없다고 정리했다. 이 표가 그 구분을 수치로 보여 준다. bagging 의 기본 모델로 가지치기하지 않은 깊은 나무를 쓰는 이유도 여기에 있다. 깊은 나무는 bias 가 작고 variance 가 크므로, bagging 이 줄일 수 있는 오차가 가장 많다.

# H) Bagging 과 boosting 은 줄이는 오차가 다르다

[[boosting]] 도 모델 여러 개의 예측을 합치지만 모델을 만드는 방식이 다르다. bagging 은 모델들을 서로 독립으로 동시에 학습한다. boosting 은 모델을 하나씩 차례로 추가하고, 새 모델이 지금까지의 앙상블이 틀린 부분을 맞추도록 학습한다. 회귀에서 많이 쓰는 [[Gradient Boosting Machine|gradient boosting]] 은 각 학습 샘플의 남은 오차(실제 $y$ − 현재 앙상블의 예측)를 새 나무의 target 으로 삼고, 새 나무의 예측에 작은 비율(learning rate)을 곱해 앙상블에 더한다.

앞 절의 깊이 1 decision tree 100 개를 learning rate 0.1 로 gradient boosting 해서 bagging 과 비교했다. 데이터와 반복 횟수는 앞 절과 같다.

| 방법 (깊이 1 나무 100 개) | test RMSE | bias² | variance |
| --- | --- | --- | --- |
| 나무 하나 | 0.447 | 0.072 | 0.040 |
| bagging | 0.421 | 0.070 | 0.019 |
| gradient boosting | 0.349 | 0.009 | 0.023 |

bagging 은 bias² 를 0.072 에서 0.070 으로 거의 그대로 두었다. boosting 은 0.009 로 8 분의 1 로 줄였다. 계단 두 개짜리 나무를 차례로 더하면서 앞의 나무가 틀린 구간을 다음 나무가 고쳐, 합쳐진 예측이 여러 계단으로 사인 곡선을 따라가기 때문이다. 같은 기본 모델에서 bagging 은 variance 를, boosting 은 bias 를 주로 줄였다.

| 기준 | bagging | boosting |
| --- | --- | --- |
| 모델을 만드는 순서 | 서로 독립, 동시에 학습 가능 | 앞 모델의 결과를 보고 차례로 학습 |
| 각 모델이 학습하는 데이터 | 서로 다른 bootstrap 표본 | 전체 데이터, 앞 모델들이 남긴 오차 |
| 예측을 합치는 방법 | 단순 평균 또는 다수결 | learning rate 를 곱해 더함 |
| 주로 줄이는 오차 | variance | bias |
| 잘 맞는 기본 모델 | 깊은 나무처럼 bias 가 작고 variance 가 큰 모델 | 얕은 나무처럼 variance 가 작고 bias 가 큰 모델 |
| 모델 수를 늘리면 | test 오차가 바닥값으로 수렴하고 다시 오르지 않음 | 학습 데이터의 남은 오차를 계속 맞추므로, 너무 많으면 overfitting 할 수 있어 검증 오차로 개수를 정함 |

# I) 실무에서 정하는 값

## I.1) 나무 수

앞의 1 차원 예제에서 평균하는 나무 수만 바꾸며 잰 test RMSE 다 (1,000 번 반복의 평균).

| 나무 수 | 1 | 2 | 5 | 10 | 20 | 50 | 100 | 200 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| test RMSE | 0.434 | 0.403 | 0.382 | 0.375 | 0.372 | 0.369 | 0.369 | 0.368 |

test RMSE 는 나무를 늘릴수록 줄다가 50 개 근처에서 평평해지고, 200 개까지 늘려도 다시 오르지 않는다. 평균의 분산 식 $\rho\sigma^2 + (1-\rho)\sigma^2/B$ 에서 나무 수가 줄일 수 있는 것은 $(1-\rho)\sigma^2/B$ 뿐이고, 이 항은 $B$ 가 커지면 0 으로 가기만 하기 때문이다. 그래서 나무 수는 overfitting 을 걱정해서 줄일 값이 아니라, 계산 비용과 test 오차가 더 줄지 않는 지점을 보고 정하는 값이다. scikit-learn `BaggingRegressor` 의 기본값은 10 개, `RandomForestRegressor` 는 100 개다.

## I.2) Bootstrap 표본의 크기

bootstrap 표본의 크기를 $N$ 보다 작게 할 수도 있다 (scikit-learn `max_samples`). 표본이 작으면 두 bootstrap 표본이 겹치는 샘플이 줄어 $\rho$ 가 내려가지만, 나무 하나가 보는 데이터가 줄어 $\sigma^2$ 가 커진다. 앞의 1 차원 예제에서 표본 크기만 바꿔 실험했다 (나무 100 개, 300 번 반복). $\rho$, $\sigma^2$, 평균의 분산은 $x = 0.95$ 에서 잰 값이다.

| 표본 크기 | 나무 사이 상관 $\rho$ | 나무 하나의 분산 $\sigma^2$ | 100 개 평균의 분산 | test RMSE |
| --- | --- | --- | --- | --- |
| $N$ (50 개) | 0.42 | 0.108 | 0.046 | 0.368 |
| $0.5N$ (25 개) | 0.22 | 0.129 | 0.029 | 0.345 |
| $0.2N$ (10 개) | 0.12 | 0.177 | 0.022 | 0.347 |

이 예제에서는 표본을 절반으로 줄였을 때 test RMSE 가 0.368 에서 0.345 로 가장 낮았다. 10 개까지 줄이면 평균의 분산은 더 작아지지만 test RMSE 는 0.347 로 오히려 조금 올랐다. 점 10 개로 학습한 나무는 계단이 몇 개뿐이라 사인 곡선을 거칠게 근사하고, 그 몫이 분산 감소를 상쇄한 것으로 보인다. 어느 크기가 가장 좋은지는 데이터에 따라 다르므로 OOB 오차나 검증 오차로 고른다.
