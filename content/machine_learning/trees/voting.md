# Voting ?

## Soft Voting

다른말로 Probability Voting 로 불리며, 각 class 별로 모델들이 예측한 probability 를 합산해서 가장 높은 class 를 선택하면 됩니다.

![[img-3fc8e37fde.png|300]]

## Hard Voting

Hard Voting 은 Majority Voting 이라고도 하며, 각각의 모델들이 결과를 예측하면 단순하게 가장 많은 표를 얻은 결과를 선택하는 것입니다.
