랜덤 포레스트는 결정 트리 여러 개를 모아 만든 숲(forest) 같은 모델이다.

# A) 결정 트리와 랜덤 포레스트

## A.1) 결정 트리 (Decision Tree)

결정 트리는 의사 결정 규칙을 나무(tree) 구조로 도식화한 모델이다. 데이터의 특징(feature)을 바탕으로 예/아니오 질문을 반복하면서 데이터를 분류하거나 값을 예측한다.

- **장점**: 예측 과정을 직관적으로 이해하고 설명하기 쉽다 (높은 해석력).
- **단점**: 데이터가 조금만 바뀌어도 구조가 크게 바뀔 수 있고, 훈련 데이터에 overfitting 되기 쉽다.
	- 특정 데이터셋에만 잘 맞아서 새 데이터에 대한 예측 성능이 떨어질 수 있다.

## A.2) 랜덤 포레스트 (Random Forest)

랜덤 포레스트는 [[ensemble]] 학습 방법 중 하나로, 결정 트리를 여러 개 만들어 그 예측을 종합한다.

- 트리 하나에만 의존하지 않고, 여러 트리의 예측을 합친다 (분류는 투표, 회귀는 평균).
- 트리마다 다른 데이터와 다른 feature 를 쓰도록 두 가지 무작위 샘플링을 한다.

## A.3) 결정 트리와 랜덤 포레스트 비교

| 구분 | 결정 트리 (Decision Tree) | 랜덤 포레스트 (Random Forest) |
| --- | --- | --- |
| 모델 구조 | 단일 나무 구조 | 여러 나무로 이뤄진 숲 구조 (ensemble) |
| Overfitting | 발생하기 쉬움 (훈련 데이터에만 치우침) | 발생 가능성이 낮음 (여러 트리의 결과를 종합) |
| 성능 (정확도) | 일반적으로 더 낮음 | 일반적으로 더 높음 |
| 해석력 | 매우 높음 (시각화해서 규칙을 이해하기 쉬움) | 매우 낮음 (수많은 트리의 결정 과정을 일일이 파악하기 어려움) |
| 학습 속도 | 빠름 (트리 하나만 만들면 됨) | 느림 (트리를 여러 개 만들어야 함) |

# B) 랜덤 포레스트의 두 가지 무작위 샘플링

랜덤 포레스트는 샘플(행)과 feature(열)를 둘 다 무작위로 샘플링한다. 이 두 가지 무작위성이 랜덤 포레스트의 핵심 원리다.

## B.1) 데이터 샘플링 (행 샘플링): [[bagging]]

- **방법**: 원본 훈련 데이터셋에서 중복을 허용해 무작위로 샘플링한다. 이를 bootstrap sampling 이라 한다.
- **예시**: 샘플이 1000 개면, 그중 1000 개를 복원 추출해 첫 번째 트리의 훈련 데이터셋을 만든다.
	- 두 번째, 세 번째 트리의 데이터셋도 같은 방식으로 각각 만든다.
	- 이 과정에서 어떤 샘플은 여러 번 뽑히고, 어떤 샘플은 한 번도 뽑히지 않을 수 있다.
- **목적**: 트리마다 다른 데이터셋으로 학습시켜 다양성을 확보한다.
	- 개별 트리가 특정 데이터에 overfitting 되는 일을 막고, 숲 전체의 일반화 성능을 높인다.

## B.2) 특성 샘플링 (열 샘플링): 무작위 노드 분할

- **방법**: 트리가 노드에서 데이터를 분할할 때, 전체 feature 중 일부만 무작위로 고르고 그 안에서만 최적의 분할 기준을 찾는다.
- **예시**: feature 가 10 개(나이, 소득, 직업 등)라면, 분기점마다 10 개를 모두 보지 않고 무작위로 3–4 개만 뽑아 그중 가장 좋은 분할 기준을 찾는다.
- **목적**: 트리 간 상관관계를 줄여 숲의 다양성을 높인다.
	- 랜덤 포레스트를 단순 bagging 과 구분 짓는 가장 중요한 특징이다.
	- 아주 강력한 예측 변수가 있으면 대부분의 트리가 그 변수를 상위 노드에서 쓰게 되어 트리끼리 비슷해진다(상관관계가 높아진다).
	- 특성 샘플링은 이 상관관계를 줄여서 개별 트리의 약점을 서로 보완하게 만든다.

## B.3) 두 샘플링 비교

| 샘플링 종류 | 대상 | 방법 | 목적 |
| --- | --- | --- | --- |
| 데이터 샘플링 | 데이터 행 (sample) | bagging / bootstrap | 트리의 다양성 확보, overfitting 방지 |
| 특성 샘플링 | 데이터 열 (feature) | 무작위로 feature 선택 후 노드 분할 | 트리 간 상관관계 감소, 다양성 극대화 |

# C) 면접 예상 질문

**Q. 랜덤 포레스트가 결정 트리에 비해 갖는 장점은?**

- 여러 결정 트리를 쓰는 ensemble 기법이라, 단일 결정 트리의 가장 큰 단점인 overfitting 을 크게 줄인다.
- 데이터와 변수를 무작위로 골라 다양한 트리를 만들기 때문에 일반화 성능이 좋고, 예측 정확도가 더 높다.
- 해석이 아주 중요한 상황이 아니면 결정 트리보다 안정적이고 좋은 성능을 기대할 수 있다.

**Q. 랜덤 포레스트의 단점은?**

- 트리를 여러 개 만들어야 해서 단일 결정 트리보다 학습 시간이 길고 메모리도 많이 쓴다.
- 수많은 트리의 예측을 종합하므로, 왜 그런 예측이 나왔는지 직관적으로 해석하기 어렵다 (black box 모델에 가깝다).
