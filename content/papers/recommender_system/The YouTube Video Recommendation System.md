# A) The YouTube Video Recommendation System ?

YouTube 추천 시스템을 초기 대규모 산업 추천 관점에서 설명한 논문이다. 이 볼트에서는 YouTube 추천 구조와 large-scale candidate generation / ranking 흐름을 연결해서 읽는 reference 로 쓰인다.

# B) 읽을 때 볼 점

현대 deep learning 기반 YouTube 추천 논문과 비교하면 모델 구조는 오래되었지만, large-scale recommendation 에서 candidate generation, ranking, feedback loop, freshness 같은 시스템적 문제가 왜 중요한지 보기 좋다.
