# A) Abstract

[[session-based recommendations|SBRS]] 에서 Next-basket 추천 (NBR) 을 위해 제안된 논문이다.

[[Recurrent Neural Network|RNN]] 모델이 sequential modeling 에 효과적이지만 추천 시나리오에서 item frequency 정보를 직접적으로 잡아낼 수 없다는 문제가 있다고 주장한다.

개인화된 아이템 빈도 (personalized item frequency, PIF) 가 부족하다고 주장함.
