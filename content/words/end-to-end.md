# A) End-to-end ?

모델의 입력이 $X$ 이고, 최종 출력 $Y$ 를 내뱉으면 이를 end-to-end 라 한다.

만약 모델의 $Z$ 를 출력하고 $Z$ 가 해당 모델 외부에서 $Y$ 를 출력하는데 사용된다면, 해당 모델은 end-to-end 가 아니다.
