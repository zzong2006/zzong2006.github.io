# A) Trino ?

Trino 는 분산 SQL query 엔진: designed to query large data sets distributed over one or more heterogeneous data sources.

# B) 유의할 점

Trino 는 일반적인 목적의 relational DB 가 아니기 때문에 MySQL, PostgreSQL 또는 Oracle 의 대체가 될 수 없다.

# C) Presto 와의 관계

원래 [[data_engineering/Presto]]SQL 라는 이름이였는데, 이게 Trino 라는 이름으로 변경된 것 (Presto 는 PrestoDB 로 이름 변경)
