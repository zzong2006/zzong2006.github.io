# Psql ?

psql 는 컨멘드 라인 기반으로 [[postgreSQL]] 에 작성된 데이터베이스에 연결하거나 테이블에서 데이터를 검색 등을 할 수 있는 도구이다.

```bash
psql -h {호스트명} -p {포트 번호} -U {사용자명} -d {데이터베이스명}
```
