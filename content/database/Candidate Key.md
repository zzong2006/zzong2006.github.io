# A) Candidate Key

Candidate Key는 tuple을 유일하게 식별하면서도 불필요한 attribute를 더 제거할 수 없는 최소 key다. 하나의 relation에는 여러 Candidate Key가 있을 수 있다.

# B) Primary Key와의 관계

여러 Candidate Key 중 실제 대표 식별자로 선택한 것이 [[database/Primary Key|Primary Key]]다. 선택되지 않은 Candidate Key는 보통 [[database/Alternate Key|Alternate Key]]라고 부른다.
