# A) click(python library) ?

CLI(Command Line Interface) 도구를 만들 수 있게 도와주는 라이브러리인 Click 에 대해 알아보자.

CLI 도구를 만들 때 가장 필요한 것은 바로 옵션이나 인자를 받아서 처리하는 것이다. 하지만 그것들을 직접 받아 파싱하고 처리하는 것이 은근히 귀찮다. Click 은 바로 이러한 귀차니즘을 해결하기 위해 다양한 기능들을 제공한다.
