# 2. `store_true`

`argparse` 를 이용해서 인자를 받고 training 시키는 형태는 수 없이 볼 수 있다. 무심코 지나쳤던 부분인데, parser 에서 `action='store_true'` 부분은 무엇일까?

* `action='store_true'`: 값이 입력되면 True 를 출력하고 아니면 False 를 출력.
* `action='store_False'`: 값이 입력되면 False 를 출력하고 아니면 True 를 출력.
