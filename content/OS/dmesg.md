# A) `dmesg` ?

dmesg 명령어는 시스템 부팅 메시지를 확인하는 명령어다. 또한 커널에서 출력되는 메세지를 일정 수준 기록하는 버퍼 역할을 수행하며, 커널 부팅 중에 에러가 났다면 어느 단계에서 에러가 났는지 범위를 좁히고 찾아내는데 도움이 된다.

# B) 사용 예시

* 모든 메세지를 삭제하며 입력 이후에 새롭게 로그 쌓기

  `dmesg -c`

* 하드 디스크 정보 확인

  `dmesg | grep sda`
