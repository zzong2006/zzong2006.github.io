# A) Onnxruntime ?

inference APIs 를 통해 [[Open Neural Network Exchange|ONNX]] 모델에 대한 inference time 속도를 빠르게 해준다.

## A.1) 장점

* 여러 언어 및 OS 의 API 를 지원한다.
* 추가적으로 학습 속도의 향상도 지원한다.
