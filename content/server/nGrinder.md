# nGrinder ?

nGrinder 는 네이버에서 성능 측정 목적으로 jython(JVM 위에서 파이썬이 동작) 으로 개발 된 오픈소스 프로젝트

* 바닥부터 개발을 한 것이 아니 라 The Grinder 라는 오픈소스 기반에서 개발
* nGrinder 는 서버에 대한 부하를 테스트하므로 서버의 성능 측정이라고도 할 수 있음
* 성능 측정이란 것은 실제 서비스에 투입하기 전, 실제와 같은 환경을 만들어 놓고 서버가 사용자를 얼만큼 수용할 수 있는지를 실험할 때 사용함
